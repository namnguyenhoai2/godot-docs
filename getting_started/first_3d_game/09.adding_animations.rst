Hoạt ảnh nhân vật
=================

Trong bài học cuối cùng này, chúng ta sẽ sử dụng các công cụ hoạt ảnh tích hợp sẵn của Godot để khiến nhân vật lơ lửng và vỗ cánh. Bạn sẽ học cách thiết kế hoạt ảnh trong trình chỉnh sửa và sử dụng mã để khiến trò chơi trở nên sống động.

|image0|

Chúng ta sẽ bắt đầu bằng phần giới thiệu về cách sử dụng trình chỉnh sửa hoạt ảnh.

Sử dụng trình chỉnh sửa hoạt ảnh
--------------------------------

Engine có sẵn các công cụ để tạo hoạt ảnh trong trình chỉnh sửa. Sau đó, bạn có thể sử dụng mã để phát và điều khiển chúng trong thời gian chạy.

Mở scene của người chơi, chọn node ``Player`` và thêm một node :ref:`AnimationPlayer <class_AnimationPlayer>`.

Dock *Animation* xuất hiện trong bảng điều khiển phía dưới.

|image1|

Dock này có một thanh công cụ và menu thả xuống hoạt ảnh ở phía trên, trình chỉnh sửa track ở giữa hiện đang trống, cùng các tùy chọn bộ lọc, snap và thu phóng ở phía dưới.

Hãy tạo một hoạt ảnh. Nhấp vào *Animation -> New*.

|image2|

Đặt tên cho hoạt ảnh là "float".

|image3|

Sau khi tạo hoạt ảnh, timeline xuất hiện với các con số biểu thị thời gian tính bằng giây.

|image4|

Chúng ta muốn hoạt ảnh tự động bắt đầu phát khi trò chơi bắt đầu. Ngoài ra, nó cũng nên lặp lại.

Để làm vậy, bạn có thể lần lượt nhấp vào nút tự động phát (|Autoplay|) trên thanh công cụ hoạt ảnh và nút mũi tên lặp.

|image5|

Bạn cũng có thể ghim trình chỉnh sửa hoạt ảnh bằng cách nhấp vào biểu tượng ghim ở góc trên bên phải. Điều này ngăn nó thu gọn khi bạn nhấp vào viewport và bỏ chọn các node.

Bạn sẽ thấy dải màu xám rộng ra một chút. Nó cho biết điểm bắt đầu và kết thúc của hoạt ảnh, còn đường màu xanh dương dọc là con trỏ thời gian.

Hoạt ảnh float
--------------

Với node animation player, bạn có thể tạo hoạt ảnh cho hầu hết các thuộc tính trên bao nhiêu node tùy ý. Hãy chú ý biểu tượng chìa khóa bên cạnh các thuộc tính trong *Inspector*. Bạn có thể nhấp vào bất kỳ biểu tượng nào để tạo một keyframe, tức một cặp thời gian và giá trị tương ứng với thuộc tính đó. Keyframe sẽ được chèn tại vị trí con trỏ thời gian trên timeline.

Hãy chèn các key đầu tiên. Ở đây, chúng ta sẽ tạo hoạt ảnh cho cả vị trí và góc xoay của node ``Character``.

Chọn ``Character``, sau đó trong *Inspector* mở rộng phần *Transform*. Nhấp vào biểu tượng chìa khóa bên cạnh *Position* và *Rotation*.

.. note::

    Một bài giảng về các nguyên tắc hoạt ảnh nằm ngoài phạm vi của hướng dẫn này. Chỉ cần lưu ý rằng bạn không nên phân bổ thời gian và khoảng cách một cách đồng đều cho mọi thứ. Thay vào đó, các nhà làm hoạt ảnh điều chỉnh thời gian và khoảng cách, hai nguyên tắc cốt lõi của hoạt ảnh. .. note::

    Hoạt ảnh cập nhật các thuộc tính của node được tạo hoạt ảnh ở mỗi frame, ghi đè lên các giá trị ban đầu. Điều khiển hoạt ảnh bằng mã
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Chúng ta có thể sử dụng mã để điều khiển việc phát hoạt ảnh dựa trên thao tác nhập của người chơi. Hãy thay đổi tốc độ hoạt ảnh khi nhân vật đang di chuyển.

Mở script của ``Player`` bằng cách nhấp vào biểu tượng script bên cạnh nó.

|image21|

Trong ``_physics_process()``, sau dòng kiểm tra vector ``direction``, hãy thêm đoạn mã sau.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _physics_process(delta): #... if direction != Vector3.ZERO: #... $AnimationPlayer.speed_scale = 4 else: $AnimationPlayer.speed_scale = 1

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta) { // ... if (direction != Vector3.Zero) { // ... GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 4; } else { GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 1; } }

Đoạn mã này khiến khi người chơi di chuyển, chúng ta nhân tốc độ phát với ``4``. Khi họ dừng lại, chúng ta đặt tốc độ về mức bình thường.

Chúng ta đã đề cập rằng ``Pivot`` có thể xếp chồng các phép biến đổi lên trên hoạt ảnh. Chúng ta có thể khiến nhân vật tạo thành một cung khi nhảy bằng dòng mã sau. Thêm dòng này vào cuối ``_physics_process()``.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _physics_process(delta): #... $Pivot.rotation.x = PI / 6 * velocity.y / jump_impulse

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta) { // ... var pivot = GetNode<Node3D>("Pivot"); pivot.Rotation = new Vector3(Mathf.Pi / 6.0f * Velocity.Y / JumpImpulse, pivot.Rotation.Y, pivot.Rotation.Z); }

Tạo hoạt ảnh cho mob
--------------------

Đây là một thủ thuật hữu ích khác với hoạt ảnh trong Godot: miễn là bạn sử dụng cấu trúc node tương tự, bạn có thể sao chép chúng sang các scene khác.

Ví dụ, cả scene ``Mob`` và ``Player`` đều có node ``Pivot`` và node ``Character``, vì vậy chúng ta có thể sử dụng lại các hoạt ảnh giữa chúng.

Mở scene *Player*, chọn node AnimationPlayer, sau đó nhấp vào **Animation > Manage Animations...**. Nhấp vào nút *Copy animation to clipboard* (hai hình vuông nhỏ) bên cạnh hoạt ảnh *float*. Nhấp OK để đóng cửa sổ.

Sau đó mở ``mob.tscn``, tạo một node con :ref:`AnimationPlayer <class_AnimationPlayer>` và chọn nó. Nhấp vào **Animation > Manage Animations**, sau đó nhấp vào **New Library**. Bạn sẽ thấy thông báo "Global library will be created." Để trống trường văn bản rồi nhấp OK. Nhấp vào biểu tượng *Paste* (bảng tạm), hoạt ảnh sẽ xuất hiện trong cửa sổ. Nhấp OK để đóng cửa sổ.

Tiếp theo, hãy đảm bảo rằng nút tự động phát (|Autoplay|) và các mũi tên lặp (Animation looping) cũng được bật trong trình chỉnh sửa hoạt ảnh ở bảng điều khiển phía dưới. Vậy là xong; tất cả quái vật giờ đây sẽ phát hoạt ảnh float.

Chúng ta có thể thay đổi tốc độ phát dựa trên ``random_speed`` của sinh vật. Mở script của *Mob* và ở cuối hàm ``initialize()``, thêm dòng sau.

.. tabs::
 .. code-tab:: gdscript GDScript

   func initialize(start_position, player_position): #... $AnimationPlayer.speed_scale = random_speed / min_speed

 .. code-tab:: csharp

    public void Initialize(Vector3 startPosition, Vector3 playerPosition) { // ... GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = randomSpeed / MinSpeed; }

Vậy là bạn đã hoàn thành phần lập trình cho trò chơi 3D hoàn chỉnh đầu tiên của mình.

**Xin chúc mừng**!

Trong phần tiếp theo, chúng ta sẽ nhanh chóng ôn lại những gì bạn đã học và cung cấp cho bạn một số liên kết để tiếp tục tìm hiểu. Nhưng trước hết, đây là ``player.gd`` và ``mob.gd`` hoàn chỉnh để bạn có thể đối chiếu mã của mình với chúng.

Đây là script *Player*.

.. tabs::
 .. code-tab:: gdscript GDScript

    extends CharacterBody3D

    signal hit

    # Tốc độ di chuyển của người chơi tính bằng mét trên giây. @export var speed = 14 # Gia tốc hướng xuống khi đang ở trên không, tính bằng mét trên giây bình phương. @export var fall_acceleration = 75 # Xung lực theo phương dọc tác dụng lên nhân vật khi nhảy, tính bằng mét trên giây. @export var jump_impulse = 20 # Xung lực theo phương dọc tác dụng lên nhân vật khi bật nảy trên một mob # tính bằng mét trên giây. @export var bounce_impulse = 16

    var target_velocity = Vector3.ZERO


    func _physics_process(delta): # Tạo một biến cục bộ để lưu hướng đầu vào var direction = Vector3.ZERO

        # Kiểm tra từng lệnh di chuyển và cập nhật hướng tương ứng if Input.is_action_pressed("move_right"): direction.x = direction.x + 1 if Input.is_action_pressed("move_left"): direction.x = direction.x - 1 if Input.is_action_pressed("move_back"): # Lưu ý rằng chúng ta đang làm việc với các trục x và z của vector. # Trong không gian 3D, mặt phẳng XZ là mặt phẳng mặt đất. direction.z = direction.z + 1 if Input.is_action_pressed("move_forward"): direction.z = direction.z - 1

        # Ngăn chuyển động chéo quá nhanh if direction != Vector3.ZERO: direction = direction.normalized() # Việc thiết lập thuộc tính basis sẽ ảnh hưởng đến phép xoay của node. $Pivot.basis = Basis.looking_at(direction) $AnimationPlayer.speed_scale = 4 else: $AnimationPlayer.speed_scale = 1

        # Vận tốc trên mặt đất target_velocity.x = direction.x * speed target_velocity.z = direction.z * speed

        # Vận tốc theo phương dọc if not is_on_floor(): # Nếu đang ở trên không, rơi xuống mặt đất target_velocity.y = target_velocity.y - (fall_acceleration * delta)

        # Nhảy. if is_on_floor() and Input.is_action_just_pressed("jump"): target_velocity.y = jump_impulse

        # Duyệt qua tất cả va chạm xảy ra trong khung hình này # trong C, tương đương với for(int i = 0; i < collisions.Count; i++) for index in range(get_slide_collision_count()): # Lấy một trong các va chạm với người chơi var collision = get_slide_collision(index)

            # Nếu va chạm với mặt đất if collision.get_collider() == null: continue

            # Nếu đối tượng va chạm là một mob if collision.get_collider().is_in_group("mob"): var mob = collision.get_collider() # kiểm tra xem chúng ta có va vào nó từ phía trên hay không. if Vector3.UP.dot(collision.get_normal()) > 0.1: # Nếu có, ép bẹp nó và bật nảy. mob.squash() target_velocity.y = bounce_impulse # Ngăn các lệnh gọi trùng lặp tiếp theo. break

        # Di chuyển Character velocity = target_velocity move_and_slide()

        $Pivot.rotation.x = PI / 6 * velocity.y / jump_impulse

    # Và hàm này ở cuối. func die(): hit.emit() queue_free()

    func _on_mob_detector_body_entered(body): die()

 .. code-tab:: csharp

    using Godot;

    public partial class Player : CharacterBody3D { // Được phát ra khi người chơi bị mob đánh trúng. [Signal] public delegate void HitEventHandler();

        // Tốc độ di chuyển của người chơi tính bằng mét trên giây. [Export] public int Speed { get; set; } = 14; // Gia tốc hướng xuống khi đang ở trên không, tính bằng mét trên giây bình phương. [Export] public int FallAcceleration { get; set; } = 75; // Xung lực theo phương dọc tác dụng lên nhân vật khi nhảy, tính bằng mét trên giây. [Export] public int JumpImpulse { get; set; } = 20; // Xung lực theo phương dọc tác dụng lên nhân vật khi bật nảy trên một mob, tính bằng mét trên giây. [Export] public int BounceImpulse { get; set; } = 16;

        private Vector3 _targetVelocity = Vector3.Zero;

        public override void _PhysicsProcess(double delta) { // Tạo một biến cục bộ để lưu hướng đầu vào. var direction = Vector3.Zero;

            // Kiểm tra từng lệnh di chuyển và cập nhật hướng tương ứng. if (Input.IsActionPressed("move_right")) { direction.X += 1.0f; } if (Input.IsActionPressed("move_left")) { direction.X -= 1.0f; } if (Input.IsActionPressed("move_back")) { // Lưu ý rằng chúng ta đang làm việc với các trục X và Z của vector. // Trong không gian 3D, mặt phẳng XZ là mặt phẳng mặt đất. direction.Z += 1.0f; } if (Input.IsActionPressed("move_forward")) { direction.Z -= 1.0f; }

            // Ngăn chuyển động chéo quá nhanh. if (direction != Vector3.Zero) { direction = direction.Normalized(); // Việc thiết lập thuộc tính basis sẽ ảnh hưởng đến phép xoay của node. GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction); GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 4; } else { GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 1; }

            // Vận tốc trên mặt đất _targetVelocity.X = direction.X * Speed; _targetVelocity.Z = direction.Z * Speed;

            // Vận tốc theo phương dọc if (!IsOnFloor()) { _targetVelocity.Y -= FallAcceleration * (float)delta; }

            // Nhảy. if (IsOnFloor() && Input.IsActionJustPressed("jump")) { _targetVelocity.Y += JumpImpulse; }

            // Duyệt qua tất cả va chạm xảy ra trong khung hình này. for (int index = 0; index < GetSlideCollisionCount(); index++) { // Lấy một trong các va chạm với người chơi. KinematicCollision3D collision = GetSlideCollision(index);

                // Nếu va chạm với một mob. if (collision.GetCollider() is Mob mob) { // Kiểm tra xem chúng ta có va vào nó từ phía trên hay không. if (Vector3.Up.Dot(collision.GetNormal()) > 0.1f) { // Nếu có, ép bẹp nó và bật nảy. mob.Squash(); _targetVelocity.Y = BounceImpulse; // Ngăn các lệnh gọi trùng lặp tiếp theo. break; } } }

            // Di chuyển nhân vật Velocity = _targetVelocity; MoveAndSlide();

            var pivot = GetNode<Node3D>("Pivot"); pivot.Rotation = new Vector3(Mathf.Pi / 6.0f * Velocity.Y / JumpImpulse, pivot.Rotation.Y, pivot.Rotation.Z); }

        private void Die() { EmitSignal(SignalName.Hit); QueueFree(); }

        private void OnMobDetectorBodyEntered(Node body) { Die(); } }
