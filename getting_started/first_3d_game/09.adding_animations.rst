Hoạt ảnh nhân vật
=================

Trong bài học cuối cùng này, chúng ta sẽ sử dụng các công cụ hoạt ảnh tích hợp sẵn của Godot để khiến nhân vật bay lơ lửng và vỗ cánh. Bạn sẽ học cách thiết kế hoạt ảnh trong editor và sử dụng code để khiến game của mình trở nên sống động.

Sử dụng animation editor
------------------------

Engine đi kèm các công cụ để tạo hoạt ảnh trong editor. Sau đó, bạn có thể sử dụng code để phát và điều khiển chúng trong runtime.

Mở player scene, chọn node ``Player`` và thêm một node :ref:`AnimationPlayer <class_AnimationPlayer>`.

Dock *Animation* xuất hiện trong panel phía dưới.

|image1|

Nó có một toolbar và menu thả xuống animation ở phía trên, một track editor hiện đang trống ở giữa, cùng các tùy chọn filter, snap và zoom ở phía dưới.

Hãy tạo một animation. Nhấp vào *Animation -> New*.

Animation float
---------------

Với node animation player, bạn có thể tạo hoạt ảnh cho hầu hết các thuộc tính trên bao nhiêu node tùy ý. Hãy chú ý biểu tượng key bên cạnh các thuộc tính trong *Inspector*. Bạn có thể nhấp vào bất kỳ biểu tượng nào để tạo một keyframe, tức một cặp thời gian và giá trị tương ứng với thuộc tính đó. Keyframe sẽ được chèn tại vị trí con trỏ thời gian trên timeline.

Hãy chèn các key đầu tiên. Ở đây, chúng ta sẽ tạo hoạt ảnh cho cả position và rotation của node ``Character``.

Chọn ``Character`` và trong *Inspector*, mở rộng phần *Transform*. Nhấp vào biểu tượng key bên cạnh *Position* và *Rotation*.

Điều khiển animation bằng code
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Chúng ta có thể sử dụng code để điều khiển việc phát animation dựa trên input của player. Hãy thay đổi tốc độ animation khi nhân vật đang di chuyển.

Mở script của ``Player`` bằng cách nhấp vào biểu tượng script bên cạnh nó.

|image21|

Trong ``_physics_process()``, sau dòng kiểm tra vector ``direction``, hãy thêm đoạn code sau.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _physics_process(delta):
       #...
       if direction != Vector3.ZERO:
           #...
           $AnimationPlayer.speed_scale = 4
       else:
           $AnimationPlayer.speed_scale = 1

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta)
    {
        // ...
        if (direction != Vector3.Zero)
        {
            // ...
            GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 4;
        }
        else
        {
            GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 1;
        }
    }

Code này khiến khi player di chuyển, chúng ta nhân tốc độ phát với ``4``. Khi player dừng lại, chúng ta đặt tốc độ về mức bình thường.

Chúng ta đã đề cập rằng ``Pivot`` có thể xếp các transform lên trên animation. Chúng ta có thể khiến nhân vật tạo thành một cung khi nhảy bằng dòng code sau. Thêm dòng này vào cuối ``_physics_process()``.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _physics_process(delta):
       #...
       $Pivot.rotation.x = PI / 6 * velocity.y / jump_impulse

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta)
    {
        // ...
        var pivot = GetNode<Node3D>("Pivot");
        pivot.Rotation = new Vector3(Mathf.Pi / 6.0f * Velocity.Y / JumpImpulse, pivot.Rotation.Y, pivot.Rotation.Z);
    }

Tạo hoạt ảnh cho mob
--------------------

Đây là một thủ thuật thú vị khác với animation trong Godot: miễn là bạn sử dụng cấu trúc node tương tự, bạn có thể sao chép chúng sang các scene khác.

Ví dụ, cả scene ``Mob`` và ``Player`` đều có node ``Pivot`` và ``Character``, nên chúng ta có thể tái sử dụng animation giữa hai scene này.

Mở scene *Player*, chọn node AnimationPlayer, sau đó nhấp vào **Animation > Manage Animations...**. Nhấp vào nút *Copy animation to clipboard* (hai hình vuông nhỏ) bên cạnh animation *float*. Nhấp OK để đóng cửa sổ.

Sau đó mở ``mob.tscn``, tạo một node con :ref:`AnimationPlayer <class_AnimationPlayer>` và chọn nó. Nhấp vào **Animation > Manage Animations**, rồi chọn **New Library**. Bạn sẽ thấy thông báo "Global library will be created." Để trống trường văn bản và nhấp OK. Nhấp vào biểu tượng *Paste* (clipboard), animation sẽ xuất hiện trong cửa sổ. Nhấp OK để đóng cửa sổ.

Tiếp theo, hãy đảm bảo rằng nút autoplay (|Autoplay|) và các mũi tên lặp (Animation looping) cũng được bật trong animation editor ở panel phía dưới. Vậy là xong; giờ đây tất cả quái vật sẽ phát animation float.

Chúng ta có thể thay đổi tốc độ phát dựa trên ``random_speed`` của sinh vật. Mở script của *Mob* và ở cuối hàm ``initialize()``, thêm dòng sau.

.. tabs::
 .. code-tab:: gdscript GDScript

   func initialize(start_position, player_position):
       #...
       $AnimationPlayer.speed_scale = random_speed / min_speed

 .. code-tab:: csharp

    public void Initialize(Vector3 startPosition, Vector3 playerPosition)
    {
        // ...
        GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = randomSpeed / MinSpeed;
    }

Vậy là bạn đã hoàn tất việc lập trình game 3D hoàn chỉnh đầu tiên của mình.

**Chúc mừng**!

Trong phần tiếp theo, chúng ta sẽ nhanh chóng ôn lại những gì bạn đã học và cung cấp một số liên kết để bạn tiếp tục tìm hiểu. Nhưng trước hết, đây là ``player.gd`` và ``mob.gd`` hoàn chỉnh để bạn có thể đối chiếu code của mình với chúng.

Đây là script *Player*.

.. tabs::
 .. code-tab:: gdscript GDScript

    extends CharacterBody3D

    signal hit

    # Tốc độ di chuyển của player tính bằng mét trên giây.
    @export var speed = 14
    # Gia tốc hướng xuống khi đang ở trên không, tính bằng mét trên giây bình phương.
    @export var fall_acceleration = 75
    # Xung lực theo phương dọc tác dụng lên nhân vật khi nhảy, tính bằng mét trên giây.
    @export var jump_impulse = 20
    # Xung lực theo phương dọc tác dụng lên nhân vật khi nảy qua một mob
    # tính bằng mét trên giây.
    @export var bounce_impulse = 16

    var target_velocity = Vector3.ZERO


    func _physics_process(delta):
        # Chúng ta tạo một biến cục bộ để lưu hướng input
        var direction = Vector3.ZERO

        # Chúng ta kiểm tra từng input di chuyển và cập nhật hướng tương ứng
        if Input.is_action_pressed("move_right"):
            direction.x = direction.x + 1
        if Input.is_action_pressed("move_left"):
            direction.x = direction.x - 1
        if Input.is_action_pressed("move_back"):
            # Hãy chú ý cách chúng ta làm việc với các trục x và z của vector.
            # Trong 3D, mặt phẳng XZ là mặt phẳng mặt đất.
            direction.z = direction.z + 1
        if Input.is_action_pressed("move_forward"):
            direction.z = direction.z - 1

        # Ngăn chuyển động theo đường chéo quá nhanh
        if direction != Vector3.ZERO:
            direction = direction.normalized()
            # Việc thiết lập thuộc tính basis sẽ ảnh hưởng đến rotation của node.
            $Pivot.basis = Basis.looking_at(direction)
            $AnimationPlayer.speed_scale = 4
        else:
            $AnimationPlayer.speed_scale = 1

        # Vận tốc trên mặt đất
        target_velocity.x = direction.x * speed
        target_velocity.z = direction.z * speed

        # Vận tốc theo phương dọc
        if not is_on_floor(): # If in the air, fall towards the floor
            target_velocity.y = target_velocity.y - (fall_acceleration * delta)

        # Nhảy.
        if is_on_floor() and Input.is_action_just_pressed("jump"):
            target_velocity.y = jump_impulse

        # Lặp qua tất cả các va chạm xảy ra trong frame này
        # trong C, đoạn này sẽ là for(int i = 0; i < collisions.Count; i++)
        for index in range(get_slide_collision_count()):
            # Chúng ta lấy một trong các va chạm với người chơi
            var collision = get_slide_collision(index)

            # Nếu va chạm là với mặt đất
            if collision.get_collider() == null:
                continue

            # Nếu collider va chạm với một mob
            if collision.get_collider().is_in_group("mob"):
                var mob = collision.get_collider()
                # chúng ta kiểm tra xem mình có đang va vào nó từ phía trên hay không.
                if Vector3.UP.dot(collision.get_normal()) > 0.1:
                    # Nếu đúng vậy, chúng ta đè bẹp nó và bật nảy lên.
                    mob.squash()
                    target_velocity.y = bounce_impulse
                    # Ngăn các lần gọi trùng lặp tiếp theo.
                    break

        # Di chuyển Character
        velocity = target_velocity
        move_and_slide()

        $Pivot.rotation.x = PI / 6 * velocity.y / jump_impulse

    # Và hàm này ở phía dưới.
    func die():
        hit.emit()
        queue_free()

    func _on_mob_detector_body_entered(body):
        die()

 .. code-tab:: csharp

    using Godot;

    public partial class Player : CharacterBody3D
    {
        // Được phát ra khi người chơi bị mob đánh trúng.
        [Signal]
        public delegate void HitEventHandler();

        // Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
        [Export]
        public int Speed { get; set; } = 14;
        // Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
        [Export]
        public int FallAcceleration { get; set; } = 75;
        // Xung lực theo phương dọc tác dụng lên nhân vật khi nhảy, tính bằng mét trên giây.
        [Export]
        public int JumpImpulse { get; set; } = 20;
        // Xung lực theo phương dọc tác dụng lên nhân vật khi bật nảy lên một mob, tính bằng mét trên giây.
        [Export]
        public int BounceImpulse { get; set; } = 16;

        private Vector3 _targetVelocity = Vector3.Zero;

        public override void _PhysicsProcess(double delta)
        {
            // Chúng ta tạo một biến cục bộ để lưu hướng di chuyển.
            var direction = Vector3.Zero;

            // Chúng ta kiểm tra từng input di chuyển và cập nhật hướng tương ứng.
            if (Input.IsActionPressed("move_right"))
            {
                direction.X += 1.0f;
            }
            if (Input.IsActionPressed("move_left"))
            {
                direction.X -= 1.0f;
            }
            if (Input.IsActionPressed("move_back"))
            {
                // Hãy chú ý rằng chúng ta đang làm việc với các trục X và Z của vector.
                // Trong không gian 3D, mặt phẳng XZ là mặt phẳng mặt đất.
                direction.Z += 1.0f;
            }
            if (Input.IsActionPressed("move_forward"))
            {
                direction.Z -= 1.0f;
            }

            // Ngăn việc di chuyển theo đường chéo nhanh hơn.
            if (direction != Vector3.Zero)
            {
                direction = direction.Normalized();
                // Việc thiết lập thuộc tính basis sẽ ảnh hưởng đến rotation của node.
                GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction);
                GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 4;
            }
            else
            {
                GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 1;
            }

            // Vận tốc trên mặt đất
            _targetVelocity.X = direction.X * Speed;
            _targetVelocity.Z = direction.Z * Speed;

            // Vận tốc theo phương dọc
            if (!IsOnFloor())
            {
                _targetVelocity.Y -= FallAcceleration * (float)delta;
            }

            // Đang nhảy.
            if (IsOnFloor() && Input.IsActionJustPressed("jump"))
            {
                _targetVelocity.Y += JumpImpulse;
            }

            // Duyệt qua tất cả các va chạm xảy ra trong frame này.
            for (int index = 0; index < GetSlideCollisionCount(); index++)
            {
                // Chúng ta lấy một trong các va chạm với người chơi.
                KinematicCollision3D collision = GetSlideCollision(index);

                // Nếu va chạm là với một mob.
                if (collision.GetCollider() is Mob mob)
                {
                    // Chúng ta kiểm tra xem mình có đang va vào nó từ phía trên hay không.
                    if (Vector3.Up.Dot(collision.GetNormal()) > 0.1f)
                    {
                        // Nếu đúng vậy, chúng ta đè bẹp nó và bật nảy lên.
                        mob.Squash();
                        _targetVelocity.Y = BounceImpulse;
                        // Ngăn các lần gọi trùng lặp tiếp theo.
                        break;
                    }
                }
            }

            // Di chuyển character
            Velocity = _targetVelocity;
            MoveAndSlide();

            var pivot = GetNode<Node3D>("Pivot");
            pivot.Rotation = new Vector3(Mathf.Pi / 6.0f * Velocity.Y / JumpImpulse, pivot.Rotation.Y, pivot.Rotation.Z);
        }

        private void Die()
        {
            EmitSignal(SignalName.Hit);
            QueueFree();
        }

        private void OnMobDetectorBodyEntered(Node body)
        {
            Die();
        }
    }
