Di chuyển người chơi bằng code
==============================

Đã đến lúc viết code! Chúng ta sẽ sử dụng các input action đã tạo ở phần trước để di chuyển nhân vật.

.. note:: Trong project này, chúng ta sẽ tuân theo quy ước đặt tên của Godot.

          - **GDScript**: Class (node) sử dụng PascalCase, biến và hàm sử dụng snake_case, còn hằng số sử dụng ALL_CAPS (Xem
            :ref:`doc_gdscript_styleguide`).

          - **C#**: Class, biến export và method sử dụng PascalCase, field private sử dụng _camelCase, biến cục bộ và parameter sử dụng camelCase (Xem :ref:`doc_c_sharp_styleguide`). Hãy cẩn thận nhập chính xác tên method khi kết nối signal.

Nhấp chuột phải vào node ``Player`` và chọn *Attach Script* để thêm script mới vào node đó. Trong cửa sổ bật lên, đặt *Template* thành *Empty* trước khi nhấn nút *Create*. Chúng ta đặt thành *Empty* vì muốn tự viết code để di chuyển người chơi.

|image0|

Hãy bắt đầu với các thuộc tính của class. Chúng ta sẽ định nghĩa tốc độ di chuyển, gia tốc rơi biểu thị trọng lực và velocity dùng để di chuyển nhân vật.

.. tabs::
 .. code-tab:: gdscript GDScript

   extends CharacterBody3D

   # Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
   @export var speed = 14
   # Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
   @export var fall_acceleration = 75

   var target_velocity = Vector3.ZERO

 .. code-tab:: csharp

    using Godot;

    public partial class Player : CharacterBody3D
    {
        // Đừng quên rebuild project để editor nhận biết biến export mới.

        // Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
        [Export]
        public int Speed { get; set; } = 14;
        // Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
        [Export]
        public int FallAcceleration { get; set; } = 75;

        private Vector3 _targetVelocity = Vector3.Zero;
    }


Đây là các thuộc tính phổ biến của một moving body. ``target_velocity`` là một :ref:`vector 3D <class_Vector3>`, kết hợp tốc độ với hướng. Ở đây, chúng ta định nghĩa nó là một thuộc tính vì muốn cập nhật và tái sử dụng giá trị của nó qua các frame.

.. note::

    Các giá trị này khá khác so với code 2D vì khoảng cách được tính bằng mét. Trong 2D, một nghìn đơn vị (pixel) có thể chỉ tương ứng với một nửa chiều rộng màn hình, còn trong 3D, đó là một kilomet.

Hãy viết code cho việc di chuyển. Trước tiên, chúng ta tính vector hướng input bằng object ``Input`` toàn cục, trong ``_physics_process()``.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _physics_process(delta):
       # Chúng ta tạo một biến cục bộ để lưu hướng input.
       var direction = Vector3.ZERO

       # Chúng ta kiểm tra từng input di chuyển và cập nhật hướng tương ứng.
       if Input.is_action_pressed("move_right"):
           direction.x += 1
       if Input.is_action_pressed("move_left"):
           direction.x -= 1
       if Input.is_action_pressed("move_back"):
           # Hãy chú ý rằng chúng ta đang làm việc với các trục x và z của vector.
           # Trong 3D, mặt phẳng XZ là mặt phẳng mặt đất.
           direction.z += 1
       if Input.is_action_pressed("move_forward"):
           direction.z -= 1

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta)
    {
        // Chúng ta tạo một biến cục bộ để lưu hướng input.
        var direction = Vector3.Zero;

        // Chúng ta kiểm tra từng input di chuyển và cập nhật hướng tương ứng.
        if (Input.IsActionPressed("move_right"))
        {
            direction.X += 1.0f;
        }
        if (Input.IsActionPressed("move_left"))
        {
            direction.X -= 1.0f;
        }
        if (Input.IsActionPressed("move_back"))
        {
            // Hãy chú ý rằng chúng ta đang làm việc với các trục X và Z của vector.
            // Trong 3D, mặt phẳng XZ là mặt phẳng mặt đất.
            direction.Z += 1.0f;
        }
        if (Input.IsActionPressed("move_forward"))
        {
            direction.Z -= 1.0f;
        }
    }

Ở đây, thay vì ``_process()``, chúng ta sẽ thực hiện mọi phép tính bằng hàm virtual ``_physics_process()``. Hàm này được thiết kế riêng cho code liên quan đến physics, chẳng hạn như di chuyển kinematic body hoặc rigid body. Hàm cập nhật node theo các khoảng thời gian cố định.

.. seealso::

    Để tìm hiểu thêm về sự khác biệt giữa ``_process()`` và ``_physics_process()``, hãy xem :ref:`doc_idle_and_physics_processing`.

Trước tiên, chúng ta khởi tạo một biến ``direction`` thành ``Vector3.ZERO``. Sau đó, chúng ta kiểm tra xem người chơi có đang nhấn một hoặc nhiều input ``move_*`` hay không và cập nhật các component ``x`` và ``z`` của vector tương ứng. Các component này tương ứng với các trục của mặt phẳng mặt đất.

Bốn điều kiện này cho chúng ta tám khả năng và tám hướng có thể.

Nếu người chơi nhấn đồng thời cả W và D, vector sẽ có độ dài khoảng ``1.4``. Nhưng nếu họ chỉ nhấn một phím, độ dài sẽ là ``1``. Chúng ta muốn độ dài của vector nhất quán và không di chuyển nhanh hơn theo đường chéo. Để làm vậy, chúng ta có thể gọi method ``normalized()`` của nó.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _physics_process(delta):
       #...

       if direction != Vector3.ZERO:
           direction = direction.normalized()
           # Thiết lập thuộc tính basis sẽ ảnh hưởng đến rotation của node.
           $Pivot.basis = Basis.looking_at(direction)

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta)
    {
        // ...

        if (direction != Vector3.Zero)
        {
            direction = direction.Normalized();
            // Thiết lập thuộc tính basis sẽ ảnh hưởng đến rotation của node.
            GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction);
        }
    }

Ở đây, chúng ta chỉ normalize vector nếu hướng có độ dài lớn hơn 0, nghĩa là người chơi đang nhấn một phím hướng.

Chúng ta tính hướng mà ``$Pivot`` đang nhìn bằng cách tạo một :ref:`Basis <class_Basis>` nhìn theo hướng ``direction``.

Tiếp theo, chúng ta cập nhật velocity. Chúng ta phải tính velocity trên mặt đất và tốc độ rơi riêng biệt. Hãy nhớ lùi lại một tab để các dòng này nằm bên trong hàm ``_physics_process()`` nhưng bên ngoài điều kiện vừa viết ở trên.

.. tabs::
 .. code-tab:: gdscript GDScript

    func _physics_process(delta):
        #...
        if direction != Vector3.ZERO:
            #...

        # Velocity trên mặt đất
        target_velocity.x = direction.x * speed
        target_velocity.z = direction.z * speed

        # Velocity theo chiều dọc
        if not is_on_floor(): # Nếu đang ở trên không, rơi về phía sàn. Chính là trọng lực
            target_velocity.y = target_velocity.y - (fall_acceleration * delta)

        # Di chuyển nhân vật
        velocity = target_velocity
        move_and_slide()

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta)
    {
        // ...
        if (direction != Vector3.Zero)
        {
            // ...
        }

        // Velocity trên mặt đất
        _targetVelocity.X = direction.X * Speed;
        _targetVelocity.Z = direction.Z * Speed;

        // Velocity theo chiều dọc
        if (!IsOnFloor()) // Nếu đang ở trên không, rơi về phía sàn. Chính là trọng lực
        {
            _targetVelocity.Y -= FallAcceleration * (float)delta;
        }

        // Di chuyển nhân vật
        Velocity = _targetVelocity;
        MoveAndSlide();
    }

Hàm ``CharacterBody3D.is_on_floor()`` trả về ``true`` nếu body va chạm với sàn trong frame này. Vì vậy, chúng ta chỉ áp dụng trọng lực lên ``Player`` khi nó đang ở trên không.

Đối với velocity theo chiều dọc, mỗi frame chúng ta trừ đi gia tốc rơi nhân với delta time. Dòng code này sẽ khiến nhân vật rơi ở mỗi frame, miễn là nhân vật không ở trên sàn hoặc không va chạm với sàn.

Engine vật lý chỉ có thể phát hiện các tương tác với tường, sàn hoặc các vật thể khác trong một frame nhất định nếu có chuyển động và va chạm xảy ra. Sau này, chúng ta sẽ sử dụng tính chất này để lập trình thao tác nhảy.

Ở dòng cuối, chúng ta gọi ``CharacterBody3D.move_and_slide()``, đây là một phương thức mạnh mẽ của lớp ``CharacterBody3D``, cho phép bạn di chuyển nhân vật một cách mượt mà. Nếu nhân vật va phải tường giữa chừng trong quá trình chuyển động, engine sẽ cố gắng làm mượt chuyển động đó cho bạn. Nó sử dụng giá trị *velocity* có sẵn trong :ref:`CharacterBody3D <class_CharacterBody3D>`

.. OLD TEXT: The function takes two parameters: our velocity and the up direction. It moves
.. the character and returns a leftover velocity after applying collisions. When
.. hitting the floor or a wall, the function will reduce or reset the speed in that
.. direction from you. In our case, storing the function's returned value prevents
.. the character from accumulating vertical momentum, which could otherwise get so
.. big the character would move through the ground slab after a while.

Và đó là toàn bộ phần code bạn cần để di chuyển nhân vật trên sàn.

Dưới đây là toàn bộ code ``player.gd`` để bạn tham khảo.

.. tabs::
 .. code-tab:: gdscript GDScript

    extends CharacterBody3D

    # Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
    @export var speed = 14
    # Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
    @export var fall_acceleration = 75

    var target_velocity = Vector3.ZERO


    func _physics_process(delta):
        var direction = Vector3.ZERO

        if Input.is_action_pressed("move_right"):
            direction.x += 1
        if Input.is_action_pressed("move_left"):
            direction.x -= 1
        if Input.is_action_pressed("move_back"):
            direction.z += 1
        if Input.is_action_pressed("move_forward"):
            direction.z -= 1

        if direction != Vector3.ZERO:
            direction = direction.normalized()
            # Thiết lập thuộc tính basis sẽ ảnh hưởng đến rotation của node.
            $Pivot.basis = Basis.looking_at(direction)

        # Velocity trên mặt đất
        target_velocity.x = direction.x * speed
        target_velocity.z = direction.z * speed

        # Velocity theo chiều dọc
        if not is_on_floor(): # Nếu đang ở trên không, rơi về phía sàn. Chính là trọng lực
            target_velocity.y = target_velocity.y - (fall_acceleration * delta)

        # Di chuyển nhân vật
        velocity = target_velocity
        move_and_slide()

 .. code-tab:: csharp

    using Godot;

    public partial class Player : CharacterBody3D
    {
        // Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
        [Export]
        public int Speed { get; set; } = 14;
        // Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
        [Export]
        public int FallAcceleration { get; set; } = 75;

        private Vector3 _targetVelocity = Vector3.Zero;

        public override void _PhysicsProcess(double delta)
        {
            var direction = Vector3.Zero;

            if (Input.IsActionPressed("move_right"))
            {
                direction.X += 1.0f;
            }
            if (Input.IsActionPressed("move_left"))
            {
                direction.X -= 1.0f;
            }
            if (Input.IsActionPressed("move_back"))
            {
                direction.Z += 1.0f;
            }
            if (Input.IsActionPressed("move_forward"))
            {
                direction.Z -= 1.0f;
            }

            if (direction != Vector3.Zero)
            {
                direction = direction.Normalized();
                // Thiết lập thuộc tính basis sẽ ảnh hưởng đến rotation của node.
                GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction);
            }

            // Velocity trên mặt đất
            _targetVelocity.X = direction.X * Speed;
            _targetVelocity.Z = direction.Z * Speed;

            // Velocity theo chiều dọc
            if (!IsOnFloor()) // Nếu đang ở trên không, rơi về phía sàn. Chính là trọng lực
            {
                _targetVelocity.Y -= FallAcceleration * (float)delta;
            }

            // Di chuyển nhân vật
            Velocity = _targetVelocity;
            MoveAndSlide();
        }
    }

Kiểm tra chuyển động của nhân vật
---------------------------------

Chúng ta sẽ đặt nhân vật vào scene ``Main`` để kiểm tra. Để làm vậy, trước tiên chúng ta cần instantiate nhân vật, sau đó thêm một camera. Không giống 2D, trong 3D, bạn sẽ không nhìn thấy gì nếu viewport không có camera hướng vào một đối tượng nào đó.

Lưu scene ``Player`` rồi mở scene ``Main``. Bạn có thể nhấp vào tab *Main* ở đầu editor để thực hiện việc này.

|image1|

Nếu trước đó bạn đã đóng scene, hãy đi đến dock *FileSystem* rồi nhấp đúp vào ``main.tscn`` để mở lại.

Để instantiate ``Player``, hãy nhấp chuột phải vào node ``Main`` và chọn *Instantiate Child Scene*.

|image2|

Trong cửa sổ bật lên, nhấp đúp vào ``player.tscn``. Nhân vật sẽ xuất hiện ở giữa viewport.

Thêm camera
~~~~~~~~~~~

Tiếp theo, hãy thêm camera. Giống như khi chúng ta thực hiện với *Player*\ 's *Pivot*, chúng ta sẽ tạo một rig cơ bản. Nhấp chuột phải vào node ``Main`` một lần nữa rồi chọn *Add Child Node*. Tạo một :ref:`Marker3D <class_Marker3D>` mới và đặt tên là ``CameraPivot``. Chọn ``CameraPivot`` rồi thêm một child node :ref:`Camera3D <class_Camera3D>` vào đó. Cây scene của bạn sẽ trông tương tự như sau.

|image3|

Hãy lưu ý checkbox *Preview* xuất hiện ở góc trên bên trái của chế độ xem 3D khi bạn chọn *Camera*. Bạn có thể nhấp vào đó để xem trước phép chiếu của camera trong game.

|image4|

Chúng ta sẽ sử dụng *Pivot* để xoay camera như thể nó đang ở trên một cần cẩu. Trước tiên, hãy chia chế độ xem 3D để có thể tự do điều hướng scene và xem những gì camera nhìn thấy.

Trên thanh công cụ ngay phía trên viewport, hãy nhấp vào *View*, sau đó chọn *2 Viewports*. Bạn cũng có thể nhấn :kbd:`Ctrl + 2` (:kbd:`Cmd + 2` trên macOS).

|image11|

|image5|

Trong chế độ xem phía dưới, chọn :ref:`Camera3D <class_Camera3D>` của bạn và bật camera Preview bằng cách nhấp vào checkbox.

|image6|

Trong chế độ xem phía trên, hãy đảm bảo *Camera3D* của bạn được chọn, rồi di chuyển camera khoảng ``19`` đơn vị trên trục Z (kéo mũi tên màu xanh dương).

|image7|

Đây là lúc điều kỳ diệu xảy ra. Chọn *CameraPivot* và xoay nó ``-45`` độ quanh trục X (sử dụng vòng tròn màu đỏ). Bạn sẽ thấy camera di chuyển như thể nó được gắn vào một cần cẩu.

|image8|

Bạn có thể chạy scene bằng cách nhấn :kbd:`F6` (:kbd:`Cmd + R` trên macOS), sau đó nhấn các phím mũi tên để di chuyển nhân vật.

|image9|

Chúng ta có thể thấy một khoảng trống xung quanh nhân vật do phép chiếu phối cảnh. Trong game này, thay vào đó chúng ta sẽ sử dụng phép chiếu trực giao để định khung khu vực gameplay tốt hơn và giúp người chơi dễ ước lượng khoảng cách hơn.

Chọn lại *Camera*, rồi trong *Inspector*, đặt *Projection* thành *Orthogonal* và *Size* thành ``19``. Nhân vật lúc này sẽ trông phẳng hơn và mặt đất sẽ phủ đầy phần nền.

.. note::

    Khi sử dụng camera trực giao trong Godot 4, chất lượng bóng định hướng phụ thuộc vào giá trị *Far* của camera. Giá trị *Far* càng cao thì camera có thể nhìn càng xa. Tuy nhiên, các giá trị *Far* cao hơn cũng làm giảm chất lượng bóng vì quá trình render bóng phải bao phủ một khoảng cách lớn hơn.

    Nếu bóng định hướng trông quá mờ sau khi chuyển sang camera trực giao, hãy giảm thuộc tính *Far* của camera xuống một giá trị thấp hơn, chẳng hạn như ``100``. Đừng giảm thuộc tính *Far* này quá nhiều, nếu không các đối tượng ở xa sẽ bắt đầu biến mất.

Hãy kiểm tra scene; bạn sẽ có thể di chuyển theo cả 8 hướng mà không bị xuyên qua sàn!
