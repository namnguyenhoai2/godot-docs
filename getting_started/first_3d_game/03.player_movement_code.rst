Di chuyển người chơi bằng code
==============================

Đã đến lúc viết code! Chúng ta sẽ sử dụng các input action đã tạo ở phần trước để di chuyển nhân vật.

.. note:: For this project, we will be following the Godot naming conventions.

          - **GDScript**: Các class (node) sử dụng PascalCase, biến và function sử dụng snake_case, còn hằng số sử dụng ALL_CAPS (Xem
            :ref:`doc_gdscript_styleguide`).

          - **C#**: Class, biến export và method sử dụng PascalCase, field private sử dụng _camelCase, biến local và parameter sử dụng camelCase (Xem :ref:`doc_c_sharp_styleguide`). Hãy nhập chính xác tên method khi kết nối signal.

Nhấp chuột phải vào node ``Player`` và chọn *Attach Script* để thêm script mới vào đó. Trong cửa sổ bật lên, đặt *Template* thành *Empty* trước khi nhấn nút *Create*. Chúng ta đặt thành *Empty* vì muốn tự viết code để di chuyển người chơi.

|image0|

Hãy bắt đầu với các property của class. Chúng ta sẽ định nghĩa tốc độ di chuyển, gia tốc rơi biểu thị trọng lực và một velocity dùng để di chuyển nhân vật.

.. tabs::
 .. code-tab:: gdscript GDScript

   extends CharacterBody3D

   # Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
   @export var speed = 14
   # Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
   @export var fall_acceleration = 75

   var target_velocity = Vector3.ZERO

 .. code-tab:: csharp

    using Godot;

    public partial class Player : CharacterBody3D
    {
        // Đừng quên rebuild project để editor nhận biết export variable mới.

        // Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
        [Export]
        public int Speed { get; set; } = 14;
        // Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
        [Export]
        public int FallAcceleration { get; set; } = 75;

        private Vector3 _targetVelocity = Vector3.Zero;
    }


Đây là những property phổ biến của một moving body. ``target_velocity`` là một :ref:`3D vector <class_Vector3>` kết hợp tốc độ với hướng. Ở đây, chúng ta định nghĩa nó là một property vì muốn cập nhật và sử dụng lại giá trị của nó qua các frame.

.. note::

    Các giá trị này khá khác so với code 2D vì khoảng cách được tính bằng mét. Trong 2D, một nghìn unit (pixel) có thể chỉ tương ứng với một nửa chiều rộng màn hình, còn trong 3D, đó là một kilometer.

Hãy viết code cho việc di chuyển. Trước tiên, chúng ta tính vector hướng input bằng object ``Input`` toàn cục, trong ``_physics_process()``.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _physics_process(delta):
       # Chúng ta tạo một biến local để lưu hướng input.
       var direction = Vector3.ZERO

       # Chúng ta kiểm tra từng input di chuyển và cập nhật hướng tương ứng.
       if Input.is_action_pressed("move_right"):
           direction.x += 1
       if Input.is_action_pressed("move_left"):
           direction.x -= 1
       if Input.is_action_pressed("move_back"):
           # Hãy chú ý cách chúng ta làm việc với các trục x và z của vector.
           # Trong 3D, mặt phẳng XZ là mặt phẳng mặt đất.
           direction.z += 1
       if Input.is_action_pressed("move_forward"):
           direction.z -= 1

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta)
    {
        // Chúng ta tạo một biến local để lưu hướng input.
        var direction = Vector3.Zero;

        // Chúng ta kiểm tra từng input di chuyển và cập nhật hướng tương ứng.
        if (Input.IsActionPressed("move_right"))
        {
            direction.X += 1.0f;
        }
        if (Input.IsActionPressed("move_left"))
        {
            direction.X -= 1.0f;
        }
        if (Input.IsActionPressed("move_back"))
        {
            // Hãy chú ý cách chúng ta làm việc với các trục X và Z của vector.
            // Trong 3D, mặt phẳng XZ là mặt phẳng mặt đất.
            direction.Z += 1.0f;
        }
        if (Input.IsActionPressed("move_forward"))
        {
            direction.Z -= 1.0f;
        }
    }

Ở đây, thay vì ``_process()``, chúng ta sẽ thực hiện mọi phép tính bằng virtual function ``_physics_process()``. Function này được thiết kế riêng cho code liên quan đến physics, chẳng hạn như di chuyển kinematic body hoặc rigid body. Nó cập nhật node theo các khoảng thời gian cố định.

.. seealso::

    Để tìm hiểu thêm về sự khác biệt giữa ``_process()`` và ``_physics_process()``, hãy xem :ref:`doc_idle_and_physics_processing`.

Chúng ta bắt đầu bằng cách khởi tạo một biến ``direction`` thành ``Vector3.ZERO``. Sau đó, chúng ta kiểm tra xem người chơi có nhấn một hoặc nhiều input ``move_*`` hay không và cập nhật các component ``x`` và ``z`` của vector tương ứng. Các component này tương ứng với các trục của mặt phẳng mặt đất.

Bốn điều kiện này tạo ra tám khả năng và tám hướng có thể có.

Trong trường hợp người chơi nhấn, chẳng hạn, cả W và D cùng lúc, vector sẽ có độ dài khoảng ``1.4``. Nhưng nếu họ chỉ nhấn một phím, nó sẽ có độ dài ``1``. Chúng ta muốn độ dài của vector nhất quán và không di chuyển nhanh hơn theo đường chéo. Để làm vậy, chúng ta có thể gọi method ``normalized()`` của nó.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _physics_process(delta):
       #...

       if direction != Vector3.ZERO:
           direction = direction.normalized()
           # Thiết lập property basis sẽ ảnh hưởng đến rotation của node.
           $Pivot.basis = Basis.looking_at(direction)

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta)
    {
        // ...

        if (direction != Vector3.Zero)
        {
            direction = direction.Normalized();
            // Thiết lập property basis sẽ ảnh hưởng đến rotation của node.
            GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction);
        }
    }

Ở đây, chúng ta chỉ normalize vector nếu hướng có độ dài lớn hơn 0, nghĩa là người chơi đang nhấn một phím hướng.

Chúng ta tính hướng mà ``$Pivot`` đang nhìn bằng cách tạo một :ref:`Basis <class_Basis>` hướng theo hướng ``direction``.

Tiếp theo, chúng ta cập nhật velocity. Chúng ta phải tính ground velocity và tốc độ rơi riêng biệt. Hãy nhớ lùi lại một tab để các dòng này nằm bên trong function ``_physics_process()`` nhưng bên ngoài điều kiện vừa viết ở trên.

.. tabs::
 .. code-tab:: gdscript GDScript

    func _physics_process(delta):
        #...
        if direction != Vector3.ZERO:
            #...

        # Ground Velocity
        target_velocity.x = direction.x * speed
        target_velocity.z = direction.z * speed

        # Vertical Velocity
        if not is_on_floor(): # Nếu đang ở trên không, rơi về phía sàn. Chính là trọng lực
            target_velocity.y = target_velocity.y - (fall_acceleration * delta)

        # Di chuyển nhân vật
        velocity = target_velocity
        move_and_slide()

 .. code-tab:: csharp

    public override void _PhysicsProcess(double delta)
    {
        // ...
        if (direction != Vector3.Zero)
        {
            // ...
        }

        // Ground velocity
        _targetVelocity.X = direction.X * Speed;
        _targetVelocity.Z = direction.Z * Speed;

        // Vertical velocity
        if (!IsOnFloor()) // Nếu đang ở trên không, rơi về phía sàn. Chính là trọng lực
        {
            _targetVelocity.Y -= FallAcceleration * (float)delta;
        }

        // Di chuyển nhân vật
        Velocity = _targetVelocity;
        MoveAndSlide();
    }

Function ``CharacterBody3D.is_on_floor()`` trả về ``true`` nếu body va chạm với sàn trong frame này. Vì vậy, chúng ta chỉ áp dụng trọng lực cho ``Player`` khi nó đang ở trên không.

Đối với vertical velocity, mỗi frame chúng ta trừ đi gia tốc rơi nhân với delta time. Dòng code này sẽ khiến nhân vật rơi ở mỗi frame, miễn là nó không ở trên sàn hoặc không va chạm với sàn.

Physics engine chỉ có thể phát hiện tương tác với tường, sàn hoặc các body khác trong một frame nhất định nếu có chuyển động và va chạm xảy ra. Sau này chúng ta sẽ dùng property này để viết code cho việc nhảy.

Ở dòng cuối, chúng ta gọi ``CharacterBody3D.move_and_slide()``, một method mạnh mẽ của class ``CharacterBody3D``, cho phép bạn di chuyển nhân vật một cách mượt mà. Nếu va vào tường giữa chừng khi đang di chuyển, engine sẽ cố gắng làm chuyển động mượt hơn cho bạn. Nó sử dụng giá trị *velocity* vốn có của :ref:`CharacterBody3D <class_CharacterBody3D>`

.. OLD TEXT: Function nhận hai parameter: velocity và hướng lên của chúng ta. Nó di chuyển .. nhân vật và trả về velocity còn lại sau khi áp dụng các va chạm. Khi .. va vào sàn hoặc tường, function sẽ giảm hoặc đặt lại tốc độ theo .. hướng đó từ bạn. Trong trường hợp của chúng ta, việc lưu giá trị trả về của function .. ngăn nhân vật tích lũy động lượng theo phương dọc, nếu không thì động lượng có thể trở nên .. lớn đến mức sau một thời gian nhân vật sẽ đi xuyên qua tấm sàn.

Và đó là toàn bộ code cần thiết để di chuyển nhân vật trên mặt đất.

Đây là code ``player.gd`` hoàn chỉnh để bạn tham khảo.

.. tabs::
 .. code-tab:: gdscript GDScript

    extends CharacterBody3D

    # Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
    @export var speed = 14
    # Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
    @export var fall_acceleration = 75

    var target_velocity = Vector3.ZERO


    func _physics_process(delta):
        var direction = Vector3.ZERO

        if Input.is_action_pressed("move_right"):
            direction.x += 1
        if Input.is_action_pressed("move_left"):
            direction.x -= 1
        if Input.is_action_pressed("move_back"):
            direction.z += 1
        if Input.is_action_pressed("move_forward"):
            direction.z -= 1

        if direction != Vector3.ZERO:
            direction = direction.normalized()
            # Thiết lập property basis sẽ ảnh hưởng đến rotation của node.
            $Pivot.basis = Basis.looking_at(direction)

        # Ground Velocity
        target_velocity.x = direction.x * speed
        target_velocity.z = direction.z * speed

        # Vertical Velocity
        if not is_on_floor(): # Nếu đang ở trên không, rơi về phía sàn. Chính là trọng lực
            target_velocity.y = target_velocity.y - (fall_acceleration * delta)

        # Di chuyển nhân vật
        velocity = target_velocity
        move_and_slide()

 .. code-tab:: csharp

    using Godot;

    public partial class Player : CharacterBody3D
    {
        // Tốc độ di chuyển của người chơi, tính bằng mét trên giây.
        [Export]
        public int Speed { get; set; } = 14;
        // Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
        [Export]
        public int FallAcceleration { get; set; } = 75;

        private Vector3 _targetVelocity = Vector3.Zero;

        public override void _PhysicsProcess(double delta)
        {
            var direction = Vector3.Zero;

            if (Input.IsActionPressed("move_right"))
            {
                direction.X += 1.0f;
            }
            if (Input.IsActionPressed("move_left"))
            {
                direction.X -= 1.0f;
            }
            if (Input.IsActionPressed("move_back"))
            {
                direction.Z += 1.0f;
            }
            if (Input.IsActionPressed("move_forward"))
            {
                direction.Z -= 1.0f;
            }

            if (direction != Vector3.Zero)
            {
                direction = direction.Normalized();
                // Thiết lập property basis sẽ ảnh hưởng đến rotation của node.
                GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction);
            }

            // Ground velocity
            _targetVelocity.X = direction.X * Speed;
            _targetVelocity.Z = direction.Z * Speed;

            // Vertical velocity
            if (!IsOnFloor()) // Nếu đang ở trên không, rơi về phía sàn. Chính là trọng lực
            {
                _targetVelocity.Y -= FallAcceleration * (float)delta;
            }

            // Di chuyển nhân vật
            Velocity = _targetVelocity;
            MoveAndSlide();
        }
    }

Kiểm tra chuyển động của người chơi
-----------------------------------

Chúng ta sẽ đặt người chơi vào scene ``Main`` để kiểm tra. Để làm vậy, chúng ta cần instantiate player rồi thêm camera. Không giống 2D, trong 3D, bạn sẽ không nhìn thấy gì nếu viewport không có camera hướng vào một vật thể.

Lưu scene ``Player`` và mở scene ``Main``. Bạn có thể nhấp vào tab *Main* ở phía trên editor để thực hiện việc này.

|image1|

Nếu trước đó bạn đã đóng scene, hãy chuyển đến dock *FileSystem* và nhấp đúp vào ``main.tscn`` để mở lại.

Để instantiate ``Player``, nhấp chuột phải vào node ``Main`` và chọn *Instantiate Child Scene*.

|image2|

Trong cửa sổ bật lên, nhấp đúp vào ``player.tscn``. Nhân vật sẽ xuất hiện ở giữa viewport.

Thêm camera
~~~~~~~~~~~

Tiếp theo, hãy thêm camera. Giống như khi tạo *Pivot* cho *Player*\ 's, chúng ta sẽ tạo một rig cơ bản. Nhấp chuột phải vào node ``Main`` một lần nữa và chọn *Add Child Node*. Tạo một :ref:`Marker3D <class_Marker3D>` mới và đặt tên là ``CameraPivot``. Chọn ``CameraPivot`` và thêm node con :ref:`Camera3D <class_Camera3D>` vào đó. Scene tree của bạn sẽ trông tương tự như sau.

|image3|

Hãy chú ý checkbox *Preview* xuất hiện ở góc trên bên trái của chế độ xem 3D khi bạn chọn *Camera*. Bạn có thể nhấp vào đó để xem trước phép chiếu camera trong game.

|image4|

Chúng ta sẽ dùng *Pivot* để xoay camera như thể nó được gắn trên một cần cẩu. Trước tiên, hãy chia chế độ xem 3D để có thể tự do điều hướng scene và xem những gì camera nhìn thấy.

Trên toolbar ngay phía trên viewport, nhấp vào *View*, sau đó nhấp vào *2 Viewports*. Bạn cũng có thể nhấn :kbd:`Ctrl + 2` (:kbd:`Cmd + 2` trên macOS).

|image11|

|image5|

Trong chế độ xem phía dưới, chọn :ref:`Camera3D <class_Camera3D>` và bật Preview của camera bằng cách nhấp vào checkbox.

|image6|

Trong chế độ xem phía trên, hãy đảm bảo *Camera3D* được chọn và di chuyển camera khoảng ``19`` unit trên trục Z (kéo mũi tên màu xanh dương).

|image7|

Đây là lúc điều kỳ diệu xảy ra. Chọn *CameraPivot* và xoay nó ``-45`` độ quanh trục X (sử dụng vòng tròn màu đỏ). Bạn sẽ thấy camera di chuyển như thể được gắn trên một cần cẩu.

|image8|

Bạn có thể chạy scene bằng cách nhấn :kbd:`F6` (:kbd:`Cmd + R` trên macOS) và nhấn các phím mũi tên để di chuyển nhân vật.

|image9|

Bạn có thể thấy một khoảng trống xung quanh nhân vật do phép chiếu phối cảnh. Trong game này, thay vào đó, chúng ta sẽ sử dụng phép chiếu trực giao để khung hình khu vực gameplay tốt hơn và giúp người chơi dễ ước lượng khoảng cách hơn.

Chọn lại *Camera* và trong *Inspector*, đặt *Projection* thành *Orthogonal* và *Size* thành ``19``. Lúc này, nhân vật sẽ trông phẳng hơn và mặt đất sẽ lấp đầy phần nền.

.. note::

    Khi sử dụng camera trực giao trong Godot 4, chất lượng directional shadow phụ thuộc vào giá trị *Far* của camera. Giá trị *Far* càng cao thì camera càng có thể nhìn xa. Tuy nhiên, giá trị *Far* cao hơn cũng làm giảm chất lượng shadow vì việc render shadow phải bao phủ một khoảng cách lớn hơn.

    Nếu directional shadow trông quá mờ sau khi chuyển sang camera trực giao, hãy giảm thuộc tính *Far* của camera xuống một giá trị thấp hơn, chẳng hạn như ``100``. Đừng giảm thuộc tính *Far* này quá nhiều, nếu không các object ở xa sẽ bắt đầu biến mất.
