Điểm số và chơi lại
===================

Trong phần này, chúng ta sẽ thêm điểm số, phát nhạc và khả năng khởi động lại trò chơi.

Chúng ta phải theo dõi điểm số hiện tại trong một biến và hiển thị điểm số trên màn hình bằng một giao diện tối giản. Chúng ta sẽ dùng một nhãn văn bản để làm việc đó.

Trong scene chính, thêm một node con :ref:`Control <class_Control>` vào ``Main`` và đặt tên là ``UserInterface``. Đảm bảo bạn đang ở màn hình 2D, nơi bạn có thể chỉnh sửa User Interface (UI) của mình.

Thêm một node :ref:`Label <class_Label>` và đặt tên là ``ScoreLabel``

|image1|

Trong *Inspector*, đặt *Text* của *Label* thành một nội dung tạm như "Score: 0".

|image2|

Ngoài ra, văn bản mặc định có màu trắng, giống như nền của trò chơi. Chúng ta cần thay đổi màu của nó để có thể nhìn thấy khi chạy.

Cuộn xuống *Theme Overrides*, mở rộng *Colors* và bật *Font Color* để tô văn bản thành màu đen (tương phản tốt với scene 3D màu trắng)

|image3|

Cuối cùng, nhấp và kéo văn bản trong viewport để di chuyển nó ra khỏi góc trên bên trái.

|image4|

Node ``UserInterface`` cho phép chúng ta nhóm UI vào một nhánh của scene tree và sử dụng một theme resource sẽ được áp dụng cho tất cả node con của nó. Chúng ta sẽ dùng nó để thiết lập font cho trò chơi.

Tạo UI theme
------------

Một lần nữa, chọn node ``UserInterface``. Trong *Inspector*, tạo một theme resource mới tại *Theme -> Theme*.

|image5|

Nhấp vào đó để mở trình chỉnh sửa theme ở panel phía dưới. Trình chỉnh sửa cho bạn xem trước giao diện của tất cả UI widget tích hợp sẵn khi sử dụng theme resource của bạn.

|image6|

Theo mặc định, một theme chỉ có một vài thuộc tính: *Default Base Scale*, *Default Font* và *Default Font Size*.

.. seealso::

    Bạn có thể thêm nhiều thuộc tính hơn vào theme resource để thiết kế các giao diện người dùng phức tạp, nhưng việc đó nằm ngoài phạm vi của series này. Để tìm hiểu thêm về cách tạo và chỉnh sửa theme, hãy xem :ref:`doc_gui_skinning`.

*Default Font* yêu cầu một tệp font giống như các tệp có trên máy tính của bạn. Hai định dạng tệp font phổ biến là TrueType Font (TTF) và OpenType Font (OTF).

Trong dock *FileSystem*, mở rộng thư mục ``fonts`` rồi nhấp và kéo tệp ``Montserrat-Medium.ttf`` mà chúng tôi đã đưa vào project lên *Default Font*. Văn bản sẽ xuất hiện lại trong phần xem trước của theme.

Văn bản hơi nhỏ. Đặt *Default Font Size* thành ``22`` pixel để tăng kích thước văn bản.

|image7|

Theo dõi điểm số
----------------

Tiếp theo, hãy làm việc với điểm số. Gắn một script mới vào ``ScoreLabel`` và định nghĩa biến ``score``.

.. tabs::
  .. code-tab:: gdscript GDScript

    extends Label

    var score = 0

  .. code-tab:: csharp

    using Godot;

    public partial class ScoreLabel : Label
    {
        private int _score = 0;
    }

Điểm số sẽ tăng thêm ``1`` mỗi khi chúng ta đè bẹp một quái vật. Chúng ta có thể dùng signal ``squashed`` của chúng để biết khi nào việc đó xảy ra. Tuy nhiên, vì chúng ta khởi tạo quái vật từ code nên không thể kết nối signal của mob với ``ScoreLabel`` thông qua editor.

Thay vào đó, chúng ta phải thực hiện kết nối từ code mỗi khi spawn một quái vật.

Mở script ``main.gd``. Nếu script vẫn đang mở, bạn có thể nhấp vào tên của nó trong cột bên trái của script editor.

|image8|

Ngoài ra, bạn có thể nhấp đúp vào tệp ``main.gd`` trong dock *FileSystem*.

Ở cuối hàm ``_on_mob_timer_timeout()``, thêm dòng sau:

.. tabs::
  .. code-tab:: gdscript GDScript

    func _on_mob_timer_timeout():
        #...
        # Chúng ta kết nối mob với score label để cập nhật điểm số sau khi đè bẹp một quái vật.
        mob.squashed.connect($UserInterface/ScoreLabel._on_mob_squashed.bind())

  .. code-tab:: csharp

    private void OnMobTimerTimeout()
    {
        // ...
        // Chúng ta kết nối mob với score label để cập nhật điểm số sau khi đè bẹp một quái vật.
        mob.Squashed += GetNode<ScoreLabel>("UserInterface/ScoreLabel").OnMobSquashed;
    }

Dòng này có nghĩa là khi mob phát signal ``squashed``, node ``ScoreLabel`` sẽ nhận signal đó và gọi hàm ``_on_mob_squashed()``.

Quay lại script ``score_label.gd`` để định nghĩa hàm callback ``_on_mob_squashed()``.

Tại đó, chúng ta tăng điểm số và cập nhật văn bản được hiển thị.

.. tabs::
  .. code-tab:: gdscript GDScript

    func _on_mob_squashed():
        score += 1
        text = "Score: %s" % score

  .. code-tab:: csharp

    public void OnMobSquashed()
    {
        _score += 1;
        Text = $"Score: {_score}";
    }

Dòng thứ hai sử dụng giá trị của biến ``score`` để thay thế placeholder ``%s``. Khi sử dụng tính năng này, Godot tự động chuyển các giá trị thành văn bản chuỗi, rất thuận tiện khi xuất văn bản trong label hoặc khi sử dụng hàm ``print()``.

.. seealso::

    Bạn có thể tìm hiểu thêm về string formatting tại đây: :ref:`doc_gdscript_printf`. Trong C#, hãy cân nhắc sử dụng `string interpolation with "$" <https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/tokens/interpolated>`_.

Bây giờ bạn có thể chơi game và đè bẹp một vài kẻ địch để xem điểm số tăng lên.

|image9|

.. note::

    Trong một game phức tạp, bạn có thể muốn tách hoàn toàn giao diện người dùng khỏi thế giới game. Khi đó, bạn sẽ không theo dõi điểm số trên label. Thay vào đó, bạn có thể lưu điểm số trong một object riêng biệt, chuyên dụng. Nhưng khi tạo prototype hoặc khi project của bạn đơn giản, việc giữ cho code đơn giản là hoàn toàn phù hợp. Lập trình luôn là một bài toán cân bằng.

Chơi lại game
-------------

Bây giờ chúng ta sẽ thêm khả năng chơi lại sau khi chết. Khi người chơi chết, chúng ta sẽ hiển thị một thông báo trên màn hình và chờ input.

Quay lại scene ``main.tscn``, chọn node ``UserInterface``, thêm node con :ref:`ColorRect <class_ColorRect>` và đặt tên là ``Retry``. Node này tô một hình chữ nhật bằng một màu đồng nhất và sẽ đóng vai trò là overlay để làm tối màn hình.

Để node bao phủ toàn bộ viewport, bạn có thể sử dụng menu *Anchor Preset* trên toolbar.

|image10|

Mở menu đó và áp dụng lệnh *Full Rect*.

|image11|

Không có gì xảy ra. Gần như vậy; chỉ có bốn ghim màu xanh lục di chuyển đến các góc của hộp chọn.

|image12|

Đó là vì các UI node (tất cả node có biểu tượng màu xanh lục) hoạt động với anchor và margin tương đối so với bounding box của node cha. Ở đây, node ``UserInterface`` có kích thước nhỏ và node ``Retry`` bị giới hạn theo nó.

Chọn ``UserInterface`` và cũng áp dụng *Anchor Preset -> Full Rect* cho nó. Node ``Retry`` lúc này sẽ bao phủ toàn bộ viewport.

Hãy thay đổi màu của nó để làm tối khu vực game. Chọn ``Retry`` và trong *Inspector*, đặt *Color* thành một màu vừa tối vừa trong suốt. Để làm vậy, trong color picker, kéo thanh trượt *A* sang trái. Nó điều khiển kênh Alpha của màu, tức là độ mờ/độ trong suốt của màu.

|image13|

Tiếp theo, thêm một :ref:`Label <class_Label>` làm con của ``Retry`` và đặt *Text* của nó là "Press Enter to retry." Để di chuyển nó và neo nó vào giữa màn hình, hãy áp dụng *Anchor Preset -> Center* cho node này.

|image14|

Lập trình tùy chọn chơi lại
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Bây giờ chúng ta có thể chuyển sang code để hiển thị và ẩn node ``Retry`` khi người chơi chết và chơi lại.

Mở script ``main.gd``. Trước tiên, chúng ta muốn ẩn overlay khi game bắt đầu. Thêm dòng này vào hàm ``_ready()``.

.. tabs::
  .. code-tab:: gdscript GDScript

   func _ready():
       $UserInterface/Retry.hide()

  .. code-tab:: csharp

    public override void _Ready()
    {
        GetNode<Control>("UserInterface/Retry").Hide();
    }

Sau đó, khi người chơi bị đánh, chúng ta hiển thị overlay.

.. tabs::
  .. code-tab:: gdscript GDScript

    func _on_player_hit():
        #...
        $UserInterface/Retry.show()

  .. code-tab:: csharp

    private void OnPlayerHit()
    {
        //...
        GetNode<Control>("UserInterface/Retry").Show();
    }

Cuối cùng, khi node ``Retry`` đang hiển thị, chúng ta cần lắng nghe input của người chơi và khởi động lại game nếu họ nhấn enter. Để làm việc này, chúng ta sử dụng callback tích hợp sẵn ``_unhandled_input()``, được kích hoạt với mọi input.

Nếu người chơi nhấn action input được định nghĩa sẵn ``ui_accept`` và ``Retry`` đang hiển thị, chúng ta reload scene hiện tại.

.. tabs::
  .. code-tab:: gdscript GDScript

    func _unhandled_input(event):
        if event.is_action_pressed("ui_accept") and $UserInterface/Retry.visible:
            # Thao tác này khởi động lại scene hiện tại.
            get_tree().reload_current_scene()

  .. code-tab:: csharp

    public override void _UnhandledInput(InputEvent @event)
    {
        if (@event.IsActionPressed("ui_accept") && GetNode<Control>("UserInterface/Retry").Visible)
        {
            // Thao tác này khởi động lại scene hiện tại.
            GetTree().ReloadCurrentScene();
        }
    }

Hàm ``get_tree()`` cho phép chúng ta truy cập object toàn cục :ref:`SceneTree <class_SceneTree>`, qua đó chúng ta có thể reload và khởi động lại scene hiện tại.

Thêm nhạc
---------

Để thêm nhạc phát liên tục ở nền, chúng ta sẽ sử dụng một tính năng khác trong Godot: :ref:`autoloads <doc_singletons_autoload>`.

Để phát audio, tất cả những gì bạn cần làm là thêm một node :ref:`AudioStreamPlayer <class_AudioStreamPlayer>` vào scene và gắn một tệp audio vào đó. Khi bạn bắt đầu scene, node có thể tự động phát. Tuy nhiên, khi bạn reload scene, như cách chúng ta làm để chơi lại, các audio node cũng được reset và nhạc sẽ phát lại từ đầu.

Bạn có thể sử dụng tính năng autoload để Godot tự động load một node hoặc một scene khi game bắt đầu, bên ngoài scene hiện tại. Bạn cũng có thể dùng nó để tạo các object có thể truy cập toàn cục.

Tạo một scene mới bằng cách vào menu *Scene* và nhấp vào *New Scene*, hoặc sử dụng biểu tượng *+* bên cạnh scene hiện đang mở.

|image15|

Nhấp vào nút *Other Node* để tạo một :ref:`AudioStreamPlayer <class_AudioStreamPlayer>` và đổi tên nó thành ``MusicPlayer``.

|image16|

Chúng tôi đã đưa một soundtrack nhạc vào thư mục ``art/``, ``House In a Forest Loop.ogg``. Nhấp và kéo nó vào thuộc tính *Stream* trong *Inspector*. Đồng thời bật *Autoplay* để nhạc tự động phát khi game bắt đầu.

|image17|

Lưu scene thành ``music_player.tscn``.

Chúng ta phải đăng ký nó dưới dạng autoload. Vào menu *Project -> Project Settings…* rồi nhấp vào tab *Globals -> Autoload*.

Trong trường *Path*, bạn cần nhập đường dẫn đến scene của mình. Nhấp vào biểu tượng thư mục để mở trình duyệt tệp và nhấp đúp vào ``music_player.tscn``. Sau đó, nhấp vào nút *Add* ở bên phải để đăng ký node.

|image18|

Bây giờ ``music_player.tscn`` sẽ được load vào mọi scene bạn mở hoặc chạy. Vì vậy, nếu bạn chạy game lúc này, nhạc sẽ tự động phát trong mọi scene.

Trước khi kết thúc bài học này, hãy xem nhanh cách tính năng này hoạt động bên dưới. Khi bạn chạy game, dock *Scene* sẽ thay đổi để hiển thị cho bạn hai tab: *Remote* và *Local*.

|image19|

Tab *Remote* cho phép bạn trực quan hóa cây node của game đang chạy. Tại đó, bạn sẽ thấy node *Main*, mọi thứ mà scene chứa và các mob được khởi tạo ở phía dưới.

|image20|

Ở trên cùng là ``MusicPlayer`` được autoload và một node *root*, chính là viewport của game.

Vậy là hoàn tất bài học này. Trong phần tiếp theo, chúng ta sẽ thêm animation để game trông đẹp mắt hơn và mang lại cảm giác chơi mượt mà hơn.

Dưới đây là script ``main.gd`` hoàn chỉnh để bạn tham khảo.

.. tabs::
  .. code-tab:: gdscript GDScript

    extends Node

    @export var mob_scene: PackedScene

    func _ready():
        $UserInterface/Retry.hide()


    func _on_mob_timer_timeout():
        # Tạo một instance mới của scene Mob.
        var mob = mob_scene.instantiate()

        # Chọn một vị trí ngẫu nhiên trên SpawnPath.
        # Chúng ta lưu tham chiếu đến node SpawnLocation.
        var mob_spawn_location = get_node("SpawnPath/SpawnLocation")
        # Và gán cho nó một offset ngẫu nhiên.
        mob_spawn_location.progress_ratio = randf()

        var player_position = $Player.position
        mob.initialize(mob_spawn_location.position, player_position)

        # Spawn mob bằng cách thêm nó vào scene Main.
        add_child(mob)

        # Chúng ta kết nối mob với label điểm số để cập nhật điểm số sau khi dẫm bẹp một con.
        mob.squashed.connect($UserInterface/ScoreLabel._on_mob_squashed.bind())

    func _on_player_hit():
        $MobTimer.stop()
        $UserInterface/Retry.show()

    func _unhandled_input(event):
        if event.is_action_pressed("ui_accept") and $UserInterface/Retry.visible:
            # Thao tác này khởi động lại scene hiện tại.
            get_tree().reload_current_scene()

  .. code-tab:: csharp

    using Godot;

    public partial class Main : Node
    {
        [Export]
        public PackedScene MobScene { get; set; }

        public override void _Ready()
        {
            GetNode<Control>("UserInterface/Retry").Hide();
        }

        public override void _UnhandledInput(InputEvent @event)
        {
            if (@event.IsActionPressed("ui_accept") && GetNode<Control>("UserInterface/Retry").Visible)
            {
                // Thao tác này khởi động lại scene hiện tại.
                GetTree().ReloadCurrentScene();
            }
        }

        private void OnMobTimerTimeout()
        {
            // Tạo một instance mới của scene Mob.
            Mob mob = MobScene.Instantiate<Mob>();

            // Chọn một vị trí ngẫu nhiên trên SpawnPath.
            // Chúng ta lưu tham chiếu đến node SpawnLocation.
            var mobSpawnLocation = GetNode<PathFollow3D>("SpawnPath/SpawnLocation");
            // Và gán cho nó một offset ngẫu nhiên.
            mobSpawnLocation.ProgressRatio = GD.Randf();

            Vector3 playerPosition = GetNode<Player>("Player").position;
            mob.Initialize(mobSpawnLocation.Position, playerPosition);

            // Spawn mob bằng cách thêm nó vào scene Main.
            AddChild(mob);

            // Chúng ta kết nối mob với label điểm số để cập nhật điểm số sau khi dẫm bẹp một con.
            mob.Squashed += GetNode<ScoreLabel>("UserInterface/ScoreLabel").OnMobSquashed;
        }

        private void OnPlayerHit()
        {
            GetNode<Timer>("MobTimer").Stop();
            GetNode<Control>("UserInterface/Retry").Show();
        }
    }
