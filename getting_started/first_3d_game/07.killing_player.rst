Tiêu diệt người chơi
====================

Chúng ta có thể tiêu diệt kẻ địch bằng cách nhảy lên chúng, nhưng người chơi vẫn chưa thể chết. Hãy sửa điều này.

Chúng ta muốn phát hiện việc bị kẻ địch đánh trúng khác với việc giẫm bẹp chúng. Chúng ta muốn người chơi chết khi đang di chuyển trên mặt đất, nhưng không chết nếu đang ở trên không. Ta có thể dùng phép toán vector để phân biệt hai loại va chạm này. Tuy nhiên, thay vào đó, chúng ta sẽ dùng một node :ref:`Area3D <class_Area3D>`, hoạt động rất hiệu quả cho các hitbox.

Hitbox với node Area
--------------------

Quay lại scene ``player.tscn`` và thêm một node con mới :ref:`Area3D <class_Area3D>`. Đặt tên cho nó là ``MobDetector`` Thêm một node :ref:`CollisionShape3D <class_CollisionShape3D>` làm node con của nó.

|image0|

Trong *Inspector*, gán cho nó một cylinder shape.

|image1|

Đây là một mẹo bạn có thể dùng để khiến va chạm chỉ xảy ra khi người chơi ở trên hoặc gần mặt đất. Bạn có thể giảm chiều cao của cylinder và di chuyển nó lên phía trên cùng của nhân vật. Nhờ vậy, khi người chơi nhảy, shape sẽ ở quá cao để kẻ địch có thể va chạm với nó.

|image2|

Bạn cũng muốn cylinder rộng hơn sphere. Nhờ vậy, người chơi sẽ bị đánh trúng trước khi va chạm và bị đẩy lên trên collision box của quái vật.

Cylinder càng rộng thì người chơi càng dễ bị tiêu diệt.

Tiếp theo, chọn lại node ``MobDetector``, rồi trong *Inspector*, **tắt** thuộc tính *Monitorable* của nó. Điều này khiến các node physics khác không thể phát hiện area. Thuộc tính *Monitoring* bổ sung cho phép nó phát hiện va chạm. Sau đó, xóa *Collision -> Layer* và đặt mask thành layer "enemies".

|image3|

Khi các area phát hiện một va chạm, chúng sẽ phát signal. Chúng ta sẽ kết nối một signal với node ``Player``. Chọn ``MobDetector`` và đi tới dock Signals, nhấp đúp vào signal ``body_entered`` rồi kết nối nó với ``Player``

|image4|

*MobDetector* sẽ phát ``body_entered`` khi một :ref:`CharacterBody3D <class_CharacterBody3D>` hoặc một
:ref:`RigidBody3D <class_RigidBody3D>` node enters it. As it only masks the "enemies" physics
layer, nó sẽ chỉ phát hiện các node ``Mob``.

Về mặt code, chúng ta sẽ làm hai việc: phát một signal mà sau này ta sẽ dùng để kết thúc game và hủy người chơi. Ta có thể bọc các thao tác này trong một function ``die()``, giúp đặt một nhãn mô tả cho đoạn code.

 .. code-tab:: gdscript GDScript

   # Đặt đoạn này ở đầu script.

   # Và function này ở cuối.

Kết thúc game
-------------

We can use the ``Player``\ 's ``hit`` signal to end the game. All we need to do is connect it to the ``Main`` node and stop the ``MobTimer`` in reaction.

Mở ``main.tscn``, chọn node ``Player``, rồi trong dock *Signals*, kết nối signal ``hit`` của nó với node ``Main``.

|image5|

Lấy timer và dừng nó trong function ``_on_player_hit()``.

.. tabs::
 .. code-tab:: gdscript GDScript

   func _on_player_hit():
       $MobTimer.stop()

 .. code-tab:: csharp

    // Chúng ta cũng đã chỉ định tên function này ở PascalCase trong cửa sổ kết nối của editor.
    private void OnPlayerHit()
    {
        GetNode<Timer>("MobTimer").Stop();
    }

Nếu thử game ngay bây giờ, quái vật sẽ ngừng xuất hiện khi bạn chết, còn những con còn lại sẽ rời khỏi màn hình.

Cũng lưu ý rằng game không còn bị crash hoặc hiển thị lỗi khi người chơi chết. Vì chúng ta dừng MobTimer nên nó không còn kích hoạt function ``_on_mob_timer_timeout()`` nữa.

Also note that the enemy colliding with the player and dying depends on the size and position of the ``Player`` and the ``Mob``\ 's collision shapes. You may need to move them and resize them to achieve a tight game feel.

Bạn có thể tự vỗ về mình: bạn đã tạo prototype cho một game 3D hoàn chỉnh, dù game vẫn còn hơi thô.

Từ đó, chúng ta sẽ thêm điểm số, tùy chọn chơi lại game, và bạn sẽ thấy cách khiến game trở nên sống động hơn nhiều chỉ với các animation tối giản.

Mốc kiểm tra code
-----------------

Dưới đây là các script hoàn chỉnh cho những node ``Main``, ``Mob`` và ``Player``, để tham khảo. Bạn có thể dùng chúng để so sánh và kiểm tra code của mình.

Bắt đầu với ``main.gd``.

.. tabs::
 .. code-tab:: gdscript GDScript

    extends Node

    @export var mob_scene: PackedScene


    func _on_mob_timer_timeout():
        # Tạo một instance mới của scene Mob.
        var mob = mob_scene.instantiate()

        # Chọn một vị trí ngẫu nhiên trên SpawnPath.
        # Chúng ta lưu tham chiếu đến node SpawnLocation.
        var mob_spawn_location = get_node("SpawnPath/SpawnLocation")
        # Và cung cấp cho nó một offset ngẫu nhiên.
        mob_spawn_location.progress_ratio = randf()

        var player_position = $Player.position
        mob.initialize(mob_spawn_location.position, player_position)

        # Spawn mob bằng cách thêm nó vào scene Main.
        add_child(mob)

    func _on_player_hit():
        $MobTimer.stop()

 .. code-tab:: csharp

    using Godot;

    public partial class Main : Node
    {
        [Export]
        public PackedScene MobScene { get; set; }

        private void OnMobTimerTimeout()
        {
            // Tạo một instance mới của scene Mob.
            Mob mob = MobScene.Instantiate<Mob>();

            // Chọn một vị trí ngẫu nhiên trên SpawnPath.
            // Chúng ta lưu tham chiếu đến node SpawnLocation.
            var mobSpawnLocation = GetNode<PathFollow3D>("SpawnPath/SpawnLocation");
            // Và cung cấp cho nó một offset ngẫu nhiên.
            mobSpawnLocation.ProgressRatio = GD.Randf();

            Vector3 playerPosition = GetNode<Player>("Player").Position;
            mob.Initialize(mobSpawnLocation.Position, playerPosition);

            // Spawn mob bằng cách thêm nó vào scene Main.
            AddChild(mob);
        }

        private void OnPlayerHit()
        {
            GetNode<Timer>("MobTimer").Stop();
        }
    }

Tiếp theo là ``mob.gd``.

.. tabs::
 .. code-tab:: gdscript GDScript

    extends CharacterBody3D

    # Tốc độ tối thiểu của mob tính bằng mét trên giây.
    @export var min_speed = 10.0
    # Tốc độ tối đa của mob tính bằng mét trên giây.
    @export var max_speed = 18.0

    # Được phát khi người chơi nhảy lên mob
    signal squashed

    func _physics_process(_delta):
        move_and_slide()

    # Function này sẽ được gọi từ scene Main.
    func initialize(start_position, player_position):
        # Chúng ta đặt vị trí của mob bằng cách đặt nó tại start_position
        # và xoay nó về phía player_position để nó nhìn vào người chơi.
        look_at_from_position(start_position, player_position, Vector3.UP)
        # Xoay mob này ngẫu nhiên trong phạm vi từ -45 đến +45 độ,
        # để nó không di chuyển thẳng về phía người chơi.
        rotate_y(randf_range(-PI / 4, PI / 4))

        # Chúng ta tính một tốc độ ngẫu nhiên (float)
        var random_speed = randf_range(min_speed, max_speed)
        # Chúng ta tính một vận tốc hướng về phía trước biểu thị cho tốc độ.
        velocity = Vector3.FORWARD * random_speed
        # Sau đó, chúng ta xoay vector vận tốc dựa trên góc xoay Y của mob
        # để di chuyển theo hướng mà mob đang nhìn.
        velocity = velocity.rotated(Vector3.UP, rotation.y)

    func _on_visible_on_screen_notifier_3d_screen_exited():
        queue_free()

    func squash():
        squashed.emit()
        queue_free() # Destroy this node

 .. code-tab:: csharp

    using Godot;

    public partial class Mob : CharacterBody3D
    {
        // Được phát khi người chơi nhảy lên mob.
        [Signal]
        public delegate void SquashedEventHandler();

        // Tốc độ tối thiểu của mob tính bằng mét trên giây
        [Export]
        public float MinSpeed { get; set; } = 10.0f;
        // Tốc độ tối đa của mob tính bằng mét trên giây
        [Export]
        public float MaxSpeed { get; set; } = 18.0f;

        public override void _PhysicsProcess(double delta)
        {
            MoveAndSlide();
        }

        // Function này sẽ được gọi từ scene Main.
        public void Initialize(Vector3 startPosition, Vector3 playerPosition)
        {
            // Chúng ta đặt vị trí của mob bằng cách đặt nó tại startPosition
            // và xoay nó về phía playerPosition để nó nhìn vào người chơi.
            LookAtFromPosition(startPosition, playerPosition, Vector3.Up);
            // Xoay mob này ngẫu nhiên trong phạm vi từ -45 đến +45 độ,
            // để nó không di chuyển thẳng về phía người chơi.
            RotateY((float)GD.RandRange(-Mathf.Pi / 4.0, Mathf.Pi / 4.0));

            // Chúng ta tính một tốc độ ngẫu nhiên (float)
            float randomSpeed = GD.RandRange(MinSpeed, MaxSpeed);
            // Chúng ta tính một vận tốc hướng về phía trước biểu thị cho tốc độ.
            Velocity = Vector3.Forward * randomSpeed;
            // Sau đó, chúng ta xoay vector vận tốc dựa trên góc xoay Y của mob
            // để di chuyển theo hướng mà mob đang nhìn.
            Velocity = Velocity.Rotated(Vector3.Up, Rotation.Y);
        }

        public void Squash()
        {
            EmitSignal(SignalName.Squashed);
            QueueFree(); // Destroy this node
        }

        private void OnVisibilityNotifierScreenExited()
        {
            QueueFree();
        }
    }

Cuối cùng là script dài nhất, ``player.gd``:

.. tabs::
 .. code-tab:: gdscript GDScript

    extends CharacterBody3D

    signal hit

    # Tốc độ di chuyển của người chơi tính bằng mét trên giây
    @export var speed = 14
    # Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
    @export var fall_acceleration = 75
    # Xung lực theo phương dọc tác dụng lên nhân vật khi nhảy, tính bằng mét trên giây.
    @export var jump_impulse = 20
    # Xung lực theo phương dọc tác dụng lên nhân vật khi bật nảy trên mob
    # tính bằng mét trên giây.
    @export var bounce_impulse = 16

    var target_velocity = Vector3.ZERO


    func _physics_process(delta):
        # Chúng ta tạo một biến cục bộ để lưu hướng input
        var direction = Vector3.ZERO

        # Chúng ta kiểm tra từng input di chuyển và cập nhật hướng tương ứng
        if Input.is_action_pressed("move_right"):
            direction.x = direction.x + 1
        if Input.is_action_pressed("move_left"):
            direction.x = direction.x - 1
        if Input.is_action_pressed("move_back"):
            # Lưu ý rằng chúng ta đang làm việc với các trục x và z của vector.
            # Trong 3D, mặt phẳng XZ là mặt phẳng mặt đất.
            direction.z = direction.z + 1
        if Input.is_action_pressed("move_forward"):
            direction.z = direction.z - 1

        # Ngăn việc di chuyển chéo nhanh vãi
        if direction != Vector3.ZERO:
            direction = direction.normalized()
            # Việc thiết lập thuộc tính basis sẽ ảnh hưởng đến phép xoay của node.
            $Pivot.basis = Basis.looking_at(direction)

        # Vận tốc mặt đất
        target_velocity.x = direction.x * speed
        target_velocity.z = direction.z * speed

        # Vận tốc theo phương dọc
        if not is_on_floor(): # If in the air, fall towards the floor. Literally gravity
            target_velocity.y = target_velocity.y - (fall_acceleration * delta)

        # Đang nhảy.
        if is_on_floor() and Input.is_action_just_pressed("jump"):
            target_velocity.y = jump_impulse

        # Duyệt qua tất cả các va chạm xảy ra trong frame này
        # trong C, đoạn này sẽ là for(int i = 0; i < collisions.Count; i++)
        for index in range(get_slide_collision_count()):
            # Chúng ta lấy một trong các va chạm với người chơi
            var collision = get_slide_collision(index)

            # Nếu va chạm là với mặt đất
            if collision.get_collider() == null:
                continue

            # Nếu collider là một mob
            if collision.get_collider().is_in_group("mob"):
                var mob = collision.get_collider()
                # chúng ta kiểm tra xem mình có đang đánh trúng nó từ phía trên hay không.
                if Vector3.UP.dot(collision.get_normal()) > 0.1:
                    # Nếu đúng, chúng ta giẫm bẹp nó và bật nảy.
                    mob.squash()
                    target_velocity.y = bounce_impulse
                    # Ngăn các lần gọi trùng lặp tiếp theo.
                    break

        # Di chuyển Character
        velocity = target_velocity
        move_and_slide()

    # Và function này ở cuối.
    func die():
        hit.emit()
        queue_free()

    func _on_mob_detector_body_entered(body):
        die()

 .. code-tab:: csharp

    using Godot;

    public partial class Player : CharacterBody3D
    {
        // Được phát khi người chơi bị mob đánh trúng.
        [Signal]
        public delegate void HitEventHandler();

        // Tốc độ di chuyển của người chơi tính bằng mét trên giây.
        [Export]
        public int Speed { get; set; } = 14;
        // Gia tốc hướng xuống khi ở trên không, tính bằng mét trên giây bình phương.
        [Export]
        public int FallAcceleration { get; set; } = 75;
        // Xung lực theo phương dọc tác dụng lên nhân vật khi nhảy, tính bằng mét trên giây.
        [Export]
        public int JumpImpulse { get; set; } = 20;
        // Xung lực theo phương dọc tác dụng lên nhân vật khi bật nảy trên mob, tính bằng mét trên giây.
        [Export]
        public int BounceImpulse { get; set; } = 16;

        private Vector3 _targetVelocity = Vector3.Zero;

        public override void _PhysicsProcess(double delta)
        {
            // Chúng ta tạo một biến cục bộ để lưu hướng input.
            var direction = Vector3.Zero;

            // Chúng ta kiểm tra từng input di chuyển và cập nhật hướng tương ứng.
            if (Input.IsActionPressed("move_right"))
            {
                direction.X += 1.0f;
            }
            if (Input.IsActionPressed("move_left"))
            {
                direction.X -= 1.0f;
            }
            if (Input.IsActionPressed("move_back"))
            {
                // Lưu ý rằng chúng ta đang làm việc với các trục X và Z của vector.
                // Trong 3D, mặt phẳng XZ là mặt phẳng mặt đất.
                direction.Z += 1.0f;
            }
            if (Input.IsActionPressed("move_forward"))
            {
                direction.Z -= 1.0f;
            }

            // Ngăn việc di chuyển chéo nhanh vãi
            if (direction != Vector3.Zero)
            {
                direction = direction.Normalized();
                // Việc thiết lập thuộc tính basis sẽ ảnh hưởng đến phép xoay của node.
                GetNode<Node3D>("Pivot").Basis = Basis.LookingAt(direction);
            }

            // Vận tốc mặt đất
            _targetVelocity.X = direction.X * Speed;
            _targetVelocity.Z = direction.Z * Speed;

            // Vận tốc theo phương dọc
            if (!IsOnFloor()) // If in the air, fall towards the floor. Literally gravity
            {
                _targetVelocity.Y -= FallAcceleration * (float)delta;
            }

            // Đang nhảy.
            if (IsOnFloor() && Input.IsActionJustPressed("jump"))
            {
                _targetVelocity.Y = JumpImpulse;
            }

            // Duyệt qua tất cả các va chạm xảy ra trong frame này.
            for (int index = 0; index < GetSlideCollisionCount(); index++)
            {
                // Chúng ta lấy một trong các va chạm với người chơi.
                KinematicCollision3D collision = GetSlideCollision(index);

                // Nếu va chạm là với một mob.
                if (collision.GetCollider() is Mob mob)
                {
                    // Chúng ta kiểm tra xem mình có đang đánh trúng nó từ phía trên hay không.
                    if (Vector3.Up.Dot(collision.GetNormal()) > 0.1f)
                    {
                        // Nếu đúng, chúng ta giẫm bẹp nó và bật nảy.
                        mob.Squash();
                        _targetVelocity.Y = BounceImpulse;
                        // Ngăn các lần gọi trùng lặp tiếp theo.
                        break;
                    }
                }
            }

            // Di chuyển Character
            Velocity = _targetVelocity;
            MoveAndSlide();
        }

        private void Die()
        {
            EmitSignal(SignalName.Hit);
            QueueFree();
        }

        private void OnMobDetectorBodyEntered(Node3D body)
        {
            Die();
        }
    }
