Nhập scene 3D
=============

Godot hỗ trợ nhập scene 3D từ nhiều định dạng tệp khác nhau. Phần tài liệu này mô tả các định dạng đó và cách sử dụng chúng, bao gồm việc export với các quy ước và best practice phù hợp, cũng như cách tùy chỉnh loại node bằng cách sử dụng hậu tố trong tên node. Bài viết về cấu hình import mô tả cách tùy chỉnh dữ liệu đã import bằng import dock, hộp thoại cài đặt import nâng cao và các scene kế thừa.
