GD0108: Nút công cụ được export không nằm trong một lớp công cụ
===============================================================

==================================== ====================================== Giá trị ==================================== ====================================== **ID quy tắc** GD0108 **Danh mục** Cách sử dụng **Bản sửa lỗi có gây breaking change hay không** Không gây breaking change **Được bật theo mặc định** Có ==================================== ======================================

Nguyên nhân
-----------

Một property được chú thích bằng attribute ``[ExportToolButton]`` trong một class **không** được chú thích bằng attribute ``[Tool]``.

Mô tả quy tắc
-------------

``[ExportToolButton]`` được dùng để tạo các nút có thể nhấp trong inspector, vì vậy, giống như mọi script khác chạy trong editor, nó cần được chú thích bằng attribute ``[Tool]``.

.. code-block:: csharp
    :emphasize-lines: 1

    [Tool]
    public partial class MyNode : Node
    {
        [ExportToolButton("Click me!")]
        public Callable ClickMeButton => Callable.From(ClickMe);

        private static void ClickMe()
        {
            GD.Print("Hello world!");
        }
    }

Cách khắc phục các vi phạm
--------------------------

Để khắc phục vi phạm quy tắc này, hãy thêm attribute ``[Tool]`` vào class chứa member được chú thích bằng attribute ``[ExportToolButton]``.

Khi nào cần bỏ qua cảnh báo
---------------------------

Không bỏ qua cảnh báo từ quy tắc này. Các nút có thể nhấp trong inspector sẽ không hoạt động nếu script của chúng không được chú thích bằng attribute ``[Tool]``.
