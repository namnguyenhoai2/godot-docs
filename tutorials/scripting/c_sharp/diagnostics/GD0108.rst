GD0108: Nút công cụ được export không nằm trong một lớp công cụ
===============================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0108
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một thuộc tính được chú thích bằng attribute ``[ExportToolButton]`` trong một lớp **không** được chú thích bằng attribute ``[Tool]``.

Mô tả quy tắc
-------------

``[ExportToolButton]`` được dùng để tạo các nút có thể nhấp trong inspector, vì vậy, giống như mọi script khác chạy trong editor, nó cần được chú thích bằng attribute ``[Tool]``.

.. code-block:: csharp
    :emphasize-lines: 1

    [Tool]
    public partial class MyNode : Node
    {
        [ExportToolButton("Click me!")]
        public Callable ClickMeButton => Callable.From(ClickMe);

        private static void ClickMe()
        {
            GD.Print("Hello world!");
        }
    }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thêm attribute ``[Tool]`` vào lớp chứa member được chú thích bằng attribute ``[ExportToolButton]``.

Khi nào nên tắt cảnh báo
------------------------

Không nên tắt cảnh báo từ quy tắc này. Các nút có thể nhấp trong inspector sẽ không hoạt động nếu script của chúng không được chú thích bằng attribute ``[Tool]``.
