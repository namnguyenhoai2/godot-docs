GD0402: Lớp không được là generic
=================================

==================================== ====================================== Giá trị ==================================== ====================================== **ID quy tắc** GD0402 **Danh mục** Cách sử dụng **Bản sửa lỗi có phá vỡ tương thích hay không** Có phá vỡ tương thích **Được bật theo mặc định** Có ==================================== ======================================

Nguyên nhân
-----------

Một kiểu generic được chú thích bằng thuộc tính ``[GlobalClass]``.

Mô tả quy tắc
-------------

Godot editor giả định rằng mọi :ref:`global class <doc_c_sharp_global_classes>` đều có thể được khởi tạo, nhưng các kiểu generic không thể được khởi tạo vì các tham số kiểu chưa được liên kết.

.. code-block:: csharp

    // Kiểu này là một global class hợp lệ vì nó không phải là generic.
    [GlobalClass]
    class SomeType : Node { }

    // Kiểu này không phải là một global class hợp lệ vì nó là generic.
    [GlobalClass]
    class SomeGenericType<T> { }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thay đổi kiểu để loại bỏ các tham số kiểu generic hoặc xóa thuộc tính ``[GlobalClass]``.

Khi nào nên tắt cảnh báo
------------------------

Không nên tắt cảnh báo từ quy tắc này. Việc thêm ``[GlobalClass]`` vào một kiểu generic là một lỗi dễ mắc phải, và cảnh báo này giúp người dùng nhận ra rằng điều đó có thể dẫn đến các lỗi không mong muốn.
