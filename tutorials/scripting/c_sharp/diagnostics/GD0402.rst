GD0402: Lớp không được là generic
=================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0402
**Category**                          Usage
**Fix is breaking or non-breaking**   Breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một kiểu generic được chú thích bằng thuộc tính ``[GlobalClass]``.

Mô tả quy tắc
-------------

Trình chỉnh sửa Godot giả định rằng mọi :ref:`global class <doc_c_sharp_global_classes>` đều có thể được khởi tạo, nhưng các kiểu generic không thể được khởi tạo vì các tham số kiểu chưa được liên kết.

.. code-block:: csharp

    // Kiểu này là một global class hợp lệ vì nó không phải là generic.
    [GlobalClass]
    class SomeType : Node { }

    // Kiểu này không phải là một global class hợp lệ vì nó là generic.
    [GlobalClass]
    class SomeGenericType<T> { }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thay đổi kiểu để loại bỏ các tham số kiểu generic hoặc loại bỏ thuộc tính ``[GlobalClass]``.

Khi nào nên bỏ qua cảnh báo
---------------------------

Không nên bỏ qua cảnh báo từ quy tắc này. Việc thêm ``[GlobalClass]`` vào một kiểu generic là một lỗi dễ mắc phải và cảnh báo này giúp người dùng nhận ra rằng điều đó có thể dẫn đến các lỗi không mong muốn.
