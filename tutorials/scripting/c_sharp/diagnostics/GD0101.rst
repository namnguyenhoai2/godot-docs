GD0101: Thành viên được export là static
========================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0101
**Category**                          Usage
**Fix is breaking or non-breaking**   Breaking - If the ``static`` keyword is removed

                                      Không gây gián đoạn - Nếu xóa thuộc tính ``[Export]`` **Được bật theo mặc định** Có
====================================  ======================================

Nguyên nhân
-----------

Một thành viên static được chú thích bằng thuộc tính ``[Export]``. Không thể export các thành viên static.

Mô tả quy tắc
-------------

Godot không cho phép export các thành viên static.

.. code-block:: csharp

    // Không thể export các thành viên static.
    [Export]
    public static int InvalidProperty { get; set; }

    // Có thể export các thành viên instance.
    [Export]
    public int ValidProperty { get; set; }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy xóa thuộc tính ``[Export]`` hoặc xóa từ khóa ``static``.

Khi nào cần tắt cảnh báo
------------------------

Không tắt cảnh báo từ quy tắc này. Không thể export các thành viên static, vì vậy Godot sẽ bỏ qua chúng, dẫn đến lỗi runtime.
