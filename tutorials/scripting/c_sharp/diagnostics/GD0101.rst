GD0101: Thành viên được export là static
========================================

==================================== ====================================== Giá trị ==================================== ====================================== **ID quy tắc** GD0101 **Danh mục** Cách sử dụng **Việc sửa lỗi có gây breaking change hay không** Breaking - Nếu từ khóa ``static`` bị xóa

                                      Không breaking - Nếu attribute ``[Export]`` bị xóa **Được bật theo mặc định** Có ==================================== ======================================

Nguyên nhân
-----------

Một thành viên static được chú thích bằng attribute ``[Export]``. Không thể export các thành viên static.

Mô tả quy tắc
-------------

Godot không cho phép export các thành viên static.

.. code-block:: csharp

    // Không thể export các thành viên static.
    [Export]
    public static int InvalidProperty { get; set; }

    // Có thể export các thành viên instance.
    [Export]
    public int ValidProperty { get; set; }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy xóa attribute ``[Export]`` hoặc xóa từ khóa ``static``.

Khi nào nên tắt cảnh báo
------------------------

Không nên tắt cảnh báo từ quy tắc này. Không thể export các thành viên static, vì vậy Godot sẽ bỏ qua chúng, dẫn đến lỗi runtime.
