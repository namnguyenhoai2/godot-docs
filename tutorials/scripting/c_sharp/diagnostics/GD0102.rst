GD0102: Kiểu của thành viên được export không được hỗ trợ
=========================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0102
**Category**                          Usage
**Fix is breaking or non-breaking**   Breaking - If the member type is changed

                                      Không phá vỡ - Nếu thuộc tính ``[Export]`` bị xóa **Được bật theo mặc định** Có
====================================  ======================================

Nguyên nhân
-----------

Một kiểu không được hỗ trợ được chỉ định cho một thành viên có chú thích bằng thuộc tính ``[Export]`` khi một
:ref:`Variant-compatible type <c_sharp_variant_compatible_types>` is expected.

Mô tả quy tắc
-------------

Mọi thành viên được export phải tương thích với Variant để engine có thể marshal thành viên đó.

.. code-block:: csharp

    class SomeType { }

    // SomeType không phải là kiểu thành viên hợp lệ vì nó không kế thừa từ GodotObject,
    // nên không tương thích với Variant.
    [Export]
    public SomeType InvalidProperty { get; set; }

    // System.Int32 là một kiểu hợp lệ vì nó tương thích với Variant.
    [Export]
    public int ValidProperty { get; set; }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thay đổi kiểu của thành viên thành một kiểu tương thích với Variant hoặc xóa thuộc tính ``[Export]``.

Khi nào nên tắt cảnh báo
------------------------

Không nên tắt cảnh báo từ quy tắc này. Các thành viên có kiểu không thể marshal sẽ gây ra lỗi runtime.
