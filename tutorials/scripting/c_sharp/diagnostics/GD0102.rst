GD0102: Kiểu của member được export không được hỗ trợ
=====================================================

==================================== ====================================== Giá trị ==================================== ====================================== **ID quy tắc** GD0102 **Danh mục** Cách sử dụng **Bản sửa lỗi có breaking hay không** Breaking - Nếu kiểu của member được thay đổi

                                      Non-breaking - Nếu attribute ``[Export]`` được xóa **Được bật theo mặc định** Có ==================================== ======================================

Nguyên nhân
-----------

Một kiểu không được hỗ trợ được chỉ định cho một member có chú thích bằng attribute ``[Export]`` khi một
:ref:`Variant-compatible type <c_sharp_variant_compatible_types>` is expected.

Mô tả quy tắc
-------------

Mọi member được export phải tương thích với Variant để engine có thể marshal member đó.

.. code-block:: csharp

    class SomeType { }

    // SomeType không phải là kiểu member hợp lệ vì nó không kế thừa từ GodotObject,
    // do đó không tương thích với Variant.
    [Export]
    public SomeType InvalidProperty { get; set; }

    // System.Int32 là một kiểu hợp lệ vì nó tương thích với Variant.
    [Export]
    public int ValidProperty { get; set; }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thay đổi kiểu của member thành kiểu tương thích với Variant hoặc xóa attribute ``[Export]``.

Khi nào nên bỏ qua cảnh báo
---------------------------

Không nên bỏ qua cảnh báo từ quy tắc này. Các member có kiểu không thể marshal sẽ gây ra lỗi runtime.
