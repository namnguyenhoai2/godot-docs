GD0102: Kiểu của member được export không được hỗ trợ
=====================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0102
**Category**                          Usage
**Fix is breaking or non-breaking**   Breaking - If the member type is changed

                                      Non-breaking - If the ``[Export]`` attribute is removed
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một kiểu không được hỗ trợ được chỉ định cho member có chú thích bằng thuộc tính ``[Export]`` trong khi cần một
:ref:`kiểu tương thích với Variant <c_sharp_variant_compatible_types>`.

Mô tả quy tắc
-------------

Mọi member được export phải tương thích với Variant để engine có thể marshal member đó.

.. code-block:: csharp

    class SomeType { }

    // SomeType không phải là kiểu member hợp lệ vì nó không kế thừa từ GodotObject,
    // do đó nó không tương thích với Variant.
    [Export]
    public SomeType InvalidProperty { get; set; }

    // System.Int32 là một kiểu hợp lệ vì nó tương thích với Variant.
    [Export]
    public int ValidProperty { get; set; }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy đổi kiểu của member thành kiểu tương thích với Variant hoặc xóa thuộc tính ``[Export]``.

Khi nào cần bỏ qua cảnh báo
---------------------------

Không nên bỏ qua cảnh báo từ quy tắc này. Các member có kiểu không thể marshal sẽ gây ra lỗi runtime.
