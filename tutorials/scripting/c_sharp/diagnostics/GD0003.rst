GD0003: Tìm thấy nhiều class có cùng tên trong cùng một tệp script
==================================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0003
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một tệp script chứa nhiều kiểu dẫn xuất từ ``GodotObject`` có tên trùng với tệp script. Chỉ một kiểu trong tệp script được trùng với tên tệp.

Mô tả quy tắc
-------------

Godot yêu cầu các script có đường dẫn duy nhất, vì vậy mỗi kiểu phải được định nghĩa trong tệp riêng và tên kiểu phải khớp với tên tệp.

.. code-block:: csharp

    public partial class MyNode : Node { }

    namespace DifferentNamespace
    {
        // Không hợp lệ vì trong tệp này đã có một kiểu mang tên MyNode.
        public partial class MyNode : Node { }
    }

    // Không hợp lệ vì trong tệp này đã có một kiểu mang tên MyNode.
    public partial class MyNode<T> : Node { }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy chuyển từng khai báo kiểu sang một tệp khác nhau.

Khi nào nên tắt cảnh báo
------------------------

Không tắt cảnh báo từ quy tắc này. Các kiểu dẫn xuất từ ``GodotObject`` phải có đường dẫn duy nhất; nếu không, engine không thể tải script theo đường dẫn, dẫn đến các lỗi runtime ngoài dự kiến.
