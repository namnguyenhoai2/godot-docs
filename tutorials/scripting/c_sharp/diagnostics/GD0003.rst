GD0003: Tìm thấy nhiều class có cùng tên trong cùng một file script
===================================================================

==================================== ====================================== Giá trị ==================================== ====================================== **ID của quy tắc** GD0003 **Danh mục** Cách sử dụng **Bản sửa lỗi có gây breaking hay không** Không breaking **Được bật theo mặc định** Có ==================================== ======================================

Nguyên nhân
-----------

Một file script chứa nhiều kiểu kế thừa từ ``GodotObject`` với tên trùng với file script. Chỉ một kiểu trong file script được trùng với tên file.

Mô tả quy tắc
-------------

Godot yêu cầu các script có một đường dẫn duy nhất, vì vậy mỗi kiểu phải được định nghĩa trong file riêng và tên kiểu phải khớp với tên file.

.. code-block:: csharp

    public partial class MyNode : Node { }

    namespace DifferentNamespace
    {
        // Không hợp lệ vì đã có một kiểu có tên MyNode trong file này.
        public partial class MyNode : Node { }
    }

    // Không hợp lệ vì đã có một kiểu có tên MyNode trong file này.
    public partial class MyNode<T> : Node { }

Cách khắc phục các vi phạm
--------------------------

Để khắc phục vi phạm quy tắc này, hãy chuyển từng khai báo kiểu sang một file khác.

Khi nào nên tắt cảnh báo
------------------------

Không tắt cảnh báo từ quy tắc này. Các kiểu kế thừa từ ``GodotObject`` phải có một đường dẫn duy nhất; nếu không, engine không thể tải script theo đường dẫn, dẫn đến các lỗi runtime không mong muốn.
