GD0104: Property được export chỉ có thể ghi
===========================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0104
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một property chỉ có thể ghi được chú thích bằng attribute ``[Export]``. Không thể export các property chỉ có thể ghi.

Mô tả quy tắc
-------------

Godot không cho phép export các property chỉ có thể ghi.

.. code-block:: csharp

    private int _backingField;

    // Các property chỉ có thể ghi không thể được export.
    [Export]
    public int InvalidProperty { set => _backingField = value; }

    // Có thể export property này vì nó có cả getter và setter.
    [Export]
    public int ValidProperty { get; set; }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy đảm bảo property khai báo cả getter và setter, hoặc xóa attribute ``[Export]``.

Khi nào nên tắt cảnh báo
------------------------

Không nên tắt cảnh báo từ quy tắc này. Các member chỉ có thể ghi không thể được export, vì vậy chúng sẽ bị Godot bỏ qua, dẫn đến lỗi runtime.
