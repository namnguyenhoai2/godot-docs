GD0002: Thiếu modifier partial trong khai báo kiểu chứa các lớp lồng nhau kế thừa từ GodotObject
================================================================================================

==================================== ====================================== Giá trị ==================================== ====================================== **Mã quy tắc** GD0002 **Danh mục** Cách sử dụng **Việc khắc phục có gây breaking change hay không** Không gây breaking change **Được bật theo mặc định** Có ==================================== ======================================

Nguyên nhân
-----------

Một kiểu kế thừa từ ``GodotObject`` được chứa trong một khai báo kiểu không phải partial.

Mô tả quy tắc
-------------

Các source generator của Godot thêm code được sinh vào các kiểu do người dùng định nghĩa để triển khai việc tích hợp với engine. Source generator không thể thêm code được sinh vào các kiểu không được khai báo là partial.

.. code-block:: csharp

    public class InvalidParentType
    {
        // MyNode được chứa trong một kiểu không phải partial nên các source generator
        // không thể nâng cấp kiểu này để hoạt động với Godot.
        public partial class MyNode : Node { }
    }

    public partial class ValidParentType
    {
        // MyNode được chứa trong một kiểu partial nên các source generator
        // có thể nâng cấp kiểu này để hoạt động với Godot.
        public partial class MyNode : Node { }
    }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thêm từ khóa ``partial`` vào khai báo kiểu.

Khi nào nên tắt cảnh báo
------------------------

Không nên tắt cảnh báo từ quy tắc này. Các kiểu kế thừa từ ``GodotObject`` nhưng không phải partial không thể được source generator nâng cấp, dẫn đến các lỗi runtime không mong muốn.
