GD0002: Thiếu bổ từ partial trong khai báo kiểu chứa các lớp lồng nhau kế thừa từ GodotObject
=============================================================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0002
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một kiểu kế thừa từ ``GodotObject`` được chứa trong một khai báo kiểu không phải partial.

Mô tả quy tắc
-------------

Các trình tạo mã nguồn của Godot thêm mã được tạo vào các kiểu do người dùng định nghĩa để triển khai tích hợp với engine. Trình tạo mã nguồn không thể thêm mã được tạo vào các kiểu không được khai báo là partial.

.. code-block:: csharp

    public class InvalidParentType
    {
        // MyNode nằm trong một kiểu không phải partial nên các trình tạo mã nguồn
        // không thể nâng cấp kiểu này để hoạt động với Godot.
        public partial class MyNode : Node { }
    }

    public partial class ValidParentType
    {
        // MyNode nằm trong một kiểu partial nên các trình tạo mã nguồn
        // có thể nâng cấp kiểu này để hoạt động với Godot.
        public partial class MyNode : Node { }
    }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thêm từ khóa ``partial`` vào khai báo kiểu.

Khi nào nên loại bỏ cảnh báo
----------------------------

Không nên loại bỏ cảnh báo từ quy tắc này. Các kiểu kế thừa từ ``GodotObject`` nhưng không phải partial không thể được trình tạo mã nguồn nâng cấp, dẫn đến các lỗi runtime không mong muốn.
