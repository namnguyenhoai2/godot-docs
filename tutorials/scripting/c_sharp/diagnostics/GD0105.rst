GD0105: Property được export là một indexer
===========================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0105
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một indexer được chú thích bằng attribute ``[Export]``. Không thể export indexer.

Mô tả quy tắc
-------------

Godot không cho phép export các property indexer.

.. code-block:: csharp

    private int[] _backingField;

    // Không thể export indexer.
    [Export]
    public int this[int index]
    {
        get => _backingField[index];
        set => _backingField[index] = value;
    }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy xóa attribute ``[Export]``.

Khi nào cần suppression warning
-------------------------------

Không suppress warning từ quy tắc này. Không thể export indexer, vì vậy Godot sẽ bỏ qua chúng, dẫn đến lỗi runtime.
