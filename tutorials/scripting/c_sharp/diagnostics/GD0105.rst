GD0105: Thuộc tính được export là một indexer
=============================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0105
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một indexer được chú thích bằng thuộc tính ``[Export]``. Không thể export các indexer.

Mô tả quy tắc
-------------

Godot không cho phép export các thuộc tính indexer.

.. code-block:: csharp

    private int[] _backingField;

    // Không thể export các indexer.
    [Export]
    public int this[int index]
    {
        get => _backingField[index];
        set => _backingField[index] = value;
    }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy xóa thuộc tính ``[Export]``.

Khi nào cần bỏ qua cảnh báo
---------------------------

Không bỏ qua cảnh báo từ quy tắc này. Không thể export các indexer, vì vậy Godot sẽ bỏ qua chúng, dẫn đến lỗi runtime.
