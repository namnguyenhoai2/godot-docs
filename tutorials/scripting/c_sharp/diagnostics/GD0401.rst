GD0401: Lớp phải kế thừa từ Godot.GodotObject hoặc một lớp dẫn xuất
===================================================================

                                      Không phá vỡ tương thích - Nếu xóa thuộc tính ``[GlobalClass]`` **Được bật theo mặc định** Có ==================================== ======================================

Nguyên nhân
-----------

Một kiểu được chú thích bằng thuộc tính ``[GlobalClass]`` không kế thừa từ ``GodotObject``.

Mô tả quy tắc
-------------

``[GlobalClass]`` không có tác dụng đối với các kiểu không kế thừa từ ``GodotObject``. Mọi :ref:`global class <doc_c_sharp_global_classes>` cuối cùng đều phải kế thừa từ ``GodotObject`` để có thể được marshal.

.. code-block:: csharp

    // Kiểu này không được đăng ký làm global class vì không kế thừa từ GodotObject.
    [GlobalClass]
    class SomeType { }

    // Kiểu này là một global class vì nó kế thừa từ Godot.Node
    // mà cuối cùng kế thừa từ GodotObject.
    [GlobalClass]
    class MyNode : Node { }

    // Kiểu này là một global class vì nó kế thừa từ Godot.Resource
    // mà cuối cùng kế thừa từ GodotObject.
    [GlobalClass]
    class MyResource : Resource { }

Cách khắc phục các vi phạm
--------------------------

Để khắc phục vi phạm quy tắc này, hãy thay đổi kiểu để kế thừa từ ``GodotObject`` hoặc xóa thuộc tính ``[GlobalClass]``.

Khi nào cần bỏ qua cảnh báo
---------------------------

Không nên bỏ qua cảnh báo từ quy tắc này. Việc thêm ``[GlobalClass]`` vào một kiểu không kế thừa từ ``GodotObject`` là một lỗi dễ mắc phải, và cảnh báo này giúp người dùng nhận ra rằng điều đó có thể dẫn đến các lỗi không mong muốn.
