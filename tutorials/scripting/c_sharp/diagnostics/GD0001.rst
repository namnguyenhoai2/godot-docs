GD0001: Thiếu modifier partial trong khai báo kiểu kế thừa từ GodotObject
=========================================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0001
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một kiểu kế thừa từ ``GodotObject`` chưa được khai báo là partial.

Mô tả quy tắc
-------------

Source generator của Godot thêm mã được sinh vào các kiểu do người dùng định nghĩa để triển khai tích hợp với engine. Source generator không thể thêm mã được sinh vào các kiểu chưa được khai báo là partial.

.. code-block:: csharp

    // Source generator không thể nâng cấp kiểu này để hoạt động với Godot.
    public class InvalidNode : Node { }

    // Source generator có thể nâng cấp kiểu này để hoạt động với Godot.
    public partial class ValidNode : Node { }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thêm từ khóa ``partial`` vào khai báo kiểu.

Khi nào cần suppress cảnh báo
-----------------------------

Không suppress cảnh báo từ quy tắc này. Các kiểu kế thừa từ ``GodotObject`` nhưng không phải là partial không thể được source generator nâng cấp, dẫn đến các lỗi runtime không mong muốn.
