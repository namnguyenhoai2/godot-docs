GD0301: Đối số kiểu generic phải là kiểu tương thích với Variant
================================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0301
**Category**                          Usage
**Fix is breaking or non-breaking**   Breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một kiểu không được hỗ trợ được chỉ định cho đối số kiểu generic trong khi cần một
:ref:`kiểu tương thích với Variant <c_sharp_variant_compatible_types>`.

Mô tả quy tắc
-------------

Khi một tham số kiểu generic được chú thích bằng thuộc tính ``[MustBeVariant]``, kiểu generic phải là kiểu tương thích với Variant. Ví dụ: kiểu generic ``Godot.Collections.Array<T>`` chỉ hỗ trợ các phần tử có kiểu có thể được chuyển đổi thành Variant.

.. code-block:: csharp

    class SomeType { }

    // SomeType không phải là kiểu hợp lệ vì nó không kế thừa từ GodotObject,
    // nên không tương thích với Variant.
    var invalidArray = new Godot.Collections.Array<SomeType>();

    // System.Int32 là kiểu hợp lệ vì nó tương thích với Variant.
    var validArray = new Godot.Collections.Array<int>();

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy đổi đối số kiểu generic thành một kiểu tương thích với Variant hoặc sử dụng API khác không yêu cầu đối số kiểu generic phải là kiểu tương thích với Variant.

Khi nào cần bỏ qua cảnh báo
---------------------------

Không bỏ qua cảnh báo từ quy tắc này. API chứa các đối số kiểu generic được chú thích bằng thuộc tính ``[MustBeVariant]`` thường có yêu cầu này vì các giá trị sẽ được truyền vào engine; nếu không thể marshal kiểu đó, sẽ xảy ra lỗi runtime.
