GD0301: Đối số kiểu generic phải là kiểu tương thích với Variant
================================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0301
**Category**                          Usage
**Fix is breaking or non-breaking**   Breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một kiểu không được hỗ trợ được chỉ định cho đối số kiểu generic khi một
:ref:`Variant-compatible type <c_sharp_variant_compatible_types>` is expected.

Mô tả quy tắc
-------------

Khi một tham số kiểu generic được chú thích bằng thuộc tính ``[MustBeVariant]``, kiểu generic đó bắt buộc phải là kiểu tương thích với Variant. Ví dụ: kiểu generic ``Godot.Collections.Array<T>`` chỉ hỗ trợ các mục thuộc một kiểu có thể được chuyển đổi thành Variant.

.. code-block:: csharp

    class SomeType { }

    // SomeType không phải là một kiểu hợp lệ vì nó không kế thừa từ GodotObject,
    // do đó nó không tương thích với Variant.
    var invalidArray = new Godot.Collections.Array<SomeType>();

    // System.Int32 là một kiểu hợp lệ vì nó tương thích với Variant.
    var validArray = new Godot.Collections.Array<int>();

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy thay đổi đối số kiểu generic thành một kiểu tương thích với Variant hoặc sử dụng một API khác không yêu cầu đối số kiểu generic phải là kiểu tương thích với Variant.

Khi nào nên loại bỏ cảnh báo
----------------------------

Không nên loại bỏ cảnh báo từ quy tắc này. API chứa các đối số kiểu generic được chú thích bằng thuộc tính ``[MustBeVariant]`` thường có yêu cầu này vì các giá trị sẽ được truyền vào engine; nếu không thể marshal kiểu đó, lỗi runtime sẽ xảy ra.
