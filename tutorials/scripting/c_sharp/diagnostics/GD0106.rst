GD0106: Property được export là một triển khai interface tường minh
===================================================================

==================================== ====================================== Giá trị ==================================== ====================================== **ID quy tắc** GD0106 **Danh mục** Cách sử dụng **Bản sửa lỗi có phá vỡ tương thích hay không** Không phá vỡ tương thích **Được bật theo mặc định** Có ==================================== ======================================

Nguyên nhân
-----------

Một triển khai property interface tường minh được chú thích bằng thuộc tính ``[Export]``. Không thể export các property triển khai một interface một cách tường minh.

Mô tả quy tắc
-------------

Godot không cho phép export các triển khai property interface tường minh. Khi một member của interface được triển khai một cách tường minh, member đó bị ẩn và các consumer không thể truy cập member đó trừ khi type được chuyển đổi trước tiên thành interface. Các member được triển khai tường minh cũng có thể dùng chung tên với các member khác trong type, vì vậy có thể tạo ra xung đột tên với những member được export khác.

.. code-block:: csharp

    public interface MyInterface
    {
        public int MyProperty { get; set; }
    }

    public class MyNode1 : Node, MyInterface
    {
        // Có thể export property này vì nó triển khai interface một cách ngầm định.
        [Export]
        public int MyProperty { get; set; }
    }

    public class MyNode2 : Node, MyInterface
    {
        // Không thể export property này vì nó triển khai interface một cách tường minh.
        [Export]
        int MyInterface.MyProperty { get; set; }
    }

Cách khắc phục các vi phạm
--------------------------

Để khắc phục vi phạm quy tắc này, hãy triển khai interface một cách ngầm định hoặc xóa thuộc tính ``[Export]``.

Khi nào nên bỏ qua cảnh báo
---------------------------

Không bỏ qua cảnh báo từ quy tắc này. Không thể export các triển khai property interface tường minh, vì vậy Godot sẽ bỏ qua chúng, dẫn đến lỗi runtime.
