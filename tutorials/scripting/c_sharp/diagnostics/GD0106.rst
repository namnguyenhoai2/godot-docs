GD0106: Thuộc tính được export là một triển khai interface tường minh
=====================================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0106
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một triển khai thuộc tính interface tường minh được chú thích bằng thuộc tính ``[Export]``. Không thể export các thuộc tính triển khai interface tường minh.

Mô tả quy tắc
-------------

Godot không cho phép export các triển khai thuộc tính interface tường minh. Khi một thành viên interface được triển khai tường minh, thành viên đó sẽ bị ẩn và các consumer không thể truy cập thành viên đó trừ khi kiểu được chuyển đổi thành interface trước. Các thành viên được triển khai tường minh cũng có thể trùng tên với các thành viên khác trong kiểu, nên điều này có thể tạo ra xung đột tên với các thành viên được export khác.

.. code-block:: csharp

    public interface MyInterface
    {
        public int MyProperty { get; set; }
    }

    public class MyNode1 : Node, MyInterface
    {
        // Có thể export thuộc tính này vì nó triển khai interface ngầm định.
        [Export]
        public int MyProperty { get; set; }
    }

    public class MyNode2 : Node, MyInterface
    {
        // Không thể export thuộc tính này vì nó triển khai interface tường minh.
        [Export]
        int MyInterface.MyProperty { get; set; }
    }

Cách khắc phục vi phạm
----------------------

Để khắc phục vi phạm quy tắc này, hãy triển khai interface ngầm định hoặc xóa thuộc tính ``[Export]``.

Khi nào cần suppress cảnh báo
-----------------------------

Không suppress cảnh báo từ quy tắc này. Không thể export các triển khai thuộc tính interface tường minh, vì vậy Godot sẽ bỏ qua chúng và dẫn đến lỗi runtime.
