GD0106: Property được export là một triển khai interface tường minh
===================================================================

====================================  ======================================
                                      Value
====================================  ======================================
**Rule ID**                           GD0106
**Category**                          Usage
**Fix is breaking or non-breaking**   Non-breaking
**Enabled by default**                Yes
====================================  ======================================

Nguyên nhân
-----------

Một triển khai property interface tường minh được chú thích bằng attribute ``[Export]``. Không thể export các property triển khai một interface một cách tường minh.

Mô tả rule
----------

Godot không cho phép export các triển khai property interface tường minh. Khi một member của interface được triển khai một cách tường minh, member đó sẽ bị ẩn và consumer không thể truy cập member này trừ khi type được chuyển đổi trước thành interface. Các member được triển khai tường minh cũng có thể trùng tên với các member khác trong type, nên có thể tạo ra xung đột tên với các member khác được export.

.. code-block:: csharp

    public interface MyInterface
    {
        public int MyProperty { get; set; }
    }

    public class MyNode1 : Node, MyInterface
    {
        // Có thể export property này vì nó triển khai interface một cách ngầm định.
        [Export]
        public int MyProperty { get; set; }
    }

    public class MyNode2 : Node, MyInterface
    {
        // Không thể export property này vì nó triển khai interface một cách tường minh.
        [Export]
        int MyInterface.MyProperty { get; set; }
    }

Cách khắc phục các vi phạm
--------------------------

Để khắc phục vi phạm rule này, hãy triển khai interface một cách ngầm định hoặc xóa attribute ``[Export]``.

Khi nào nên tắt cảnh báo
------------------------

Không nên tắt cảnh báo từ rule này. Không thể export các triển khai property interface tường minh, vì vậy chúng sẽ bị Godot bỏ qua và gây ra lỗi runtime.
