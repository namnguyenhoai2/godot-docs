ARCore
======

ARCore là một API Android cho phép các ứng dụng AR dựa trên điện thoại hoạt động trên thiết bị. API này được hỗ trợ thông qua `Godot ARCore plugin. <https://github.com/godotvr/godot_arcore>`__

Để biết thêm thông tin, vui lòng tham khảo tài liệu đi kèm với plugin.

.. note::

    Plugin này **không** được Godot Foundation duy trì. Plugin hiện đang ở trạng thái không hoạt động và không được phát triển tích cực.
