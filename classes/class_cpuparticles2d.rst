CPUParticles2D
==============

**Kế thừa:** :ref:`Node2D<class_Node2D>` **<** :ref:`CanvasItem<class_CanvasItem>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Bộ phát hạt 2D dựa trên CPU.

.. rst-class:: classref-introduction-group

Mô tả
-----

Node hạt 2D dựa trên CPU, được dùng để tạo nhiều hệ thống và hiệu ứng hạt khác nhau.

Xem thêm :ref:`GPUParticles2D<class_GPUParticles2D>`, cung cấp cùng chức năng với khả năng tăng tốc phần cứng, nhưng có thể không chạy trên các thiết bị cũ.
