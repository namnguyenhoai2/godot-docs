EditorSceneFormatImporterUFBX
=============================

Mô tả
-----

EditorSceneFormatImporterUFBX được thiết kế để tải các tệp FBX và hỗ trợ cả tệp FBX nhị phân lẫn ASCII từ phiên bản 3000 trở lên. Class này hỗ trợ nhiều loại đối tượng 3D như mesh, skin, blend shape, material và thông tin rigging. Class này hướng tới việc đạt được sự tương đương về tính năng với FBX SDK chính thức và hỗ trợ các đặc tả FBX 7.4.
