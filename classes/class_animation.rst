Animation
=========

**Kế thừa:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Lưu trữ dữ liệu có thể được dùng để tạo animation cho bất kỳ thành phần nào trong engine.

.. rst-class:: classref-introduction-group

Mô tả
-----

Resource này lưu trữ dữ liệu có thể được dùng để tạo animation cho bất kỳ thành phần nào trong engine. Animation được chia thành các track và mỗi track phải được liên kết với một node. Trạng thái của node đó có thể được thay đổi theo thời gian bằng cách thêm các key được định thời gian (event) vào track.


.. tabs::

 .. code-tab:: gdscript

    # Tạo một animation khiến node "Enemy" di chuyển sang phải
    # 100 pixel trong 2.0 giây.
    var animation = Animation.new()
    var track_index = animation.add_track(Animation.TYPE_VALUE)
    animation.track_set_path(track_index, "Enemy:position:x")
    animation.track_insert_key(track_index, 0.0, 0)
    animation.track_insert_key(track_index, 2.0, 100)
    animation.length = 2.0

 .. code-tab:: csharp

    // Tạo một animation khiến node "Enemy" di chuyển sang phải
    // 100 pixel trong 2.0 giây.
    var animation = new Animation();
    int trackIndex = animation.AddTrack(Animation.TrackType.Value);
    animation.TrackSetPath(trackIndex, "Enemy:position:x");
    animation.TrackInsertKey(trackIndex, 0.0f, 0);
    animation.TrackInsertKey(trackIndex, 2.0f, 100);
    animation.Length = 2.0f;



Animation chỉ là các container dữ liệu và phải được thêm vào các node như :ref:`AnimationPlayer<class_AnimationPlayer>` để phát lại. Animation track có nhiều loại khác nhau, mỗi loại có tập method chuyên dụng riêng. Xem :ref:`TrackType<enum_Animation_TrackType>` để biết các loại hiện có.

\ **Lưu ý:** Đối với position/rotation/scale 3D, nên sử dụng các loại track :ref:`TYPE_POSITION_3D<class_Animation_constant_TYPE_POSITION_3D>`, :ref:`TYPE_ROTATION_3D<class_Animation_constant_TYPE_ROTATION_3D>` và :ref:`TYPE_SCALE_3D<class_Animation_constant_TYPE_SCALE_3D>` chuyên dụng thay cho :ref:`TYPE_VALUE<class_Animation_constant_TYPE_VALUE>` vì lý do hiệu năng.

|void| **track_set_path**\ (\ track_idx\: :ref:`int<class_int>`, path\: :ref:`NodePath<class_NodePath>`\ ) :ref:`🔗<class_Animation_method_track_set_path>`

Đặt path của một track. Path phải là path hợp lệ trong scene tree đến một node và phải được chỉ định bắt đầu từ :ref:`AnimationMixer.root_node<class_AnimationMixer_property_root_node>` sẽ phát animation. Các track điều khiển property hoặc bone phải nối thêm tên của chúng sau path, được phân tách bằng ``":"``.

Ví dụ: ``"character/skeleton:ankle"`` hoặc ``"character/mesh:transform/local"``.
