Input
=====

**Kế thừa:** :ref:`Object<class_Object>`

Một singleton dùng để xử lý đầu vào.

.. rst-class:: classref-introduction-group

Mô tả
-----

Singleton **Input** xử lý thao tác nhấn phím, nút chuột và chuyển động chuột, gamepad và các hành động đầu vào. Có thể thiết lập các hành động và sự kiện của chúng trong tab **Input Map** tại **Project > Project Settings**, hoặc bằng lớp :ref:`InputMap<class_InputMap>`.

\ **Lưu ý:** **Input**Các phương thức của singleton phản ánh trạng thái đầu vào toàn cục và không bị ảnh hưởng bởi :ref:`Control.accept_event()<class_Control_method_accept_event>` hoặc :ref:`Viewport.set_input_as_handled()<class_Viewport_method_set_input_as_handled>`, vì các phương thức đó chỉ xử lý cách đầu vào được truyền trong :ref:`SceneTree<class_SceneTree>`.

Nếu ``true``, các sự kiện đầu vào tương tự do hệ điều hành gửi sẽ được tích lũy. Có thể tắt tính năng tích lũy đầu vào để nhận dữ liệu đầu vào chính xác và phản hồi nhanh hơn một chút, với cái giá là mức sử dụng CPU tăng lên. Bắt đầu quá trình hiệu chỉnh con quay hồi chuyển của tay cầm được chỉ định, nếu tay cầm có cảm biến này.

    private const float GyroSensitivity = 10.0;

    public override void _Ready()
    {
        // Trong ví dụ này, chúng ta chỉ sử dụng joypad đầu tiên được kết nối (id 0).
        if (!Input.GetConnectedJoypads().Contains(0))
        {
            return;
        }

        if (!Input.HasJoyMotionSensors(0))
        {
            return;
        }

        // Chúng ta phải bật accelerometer và gyroscope trước khi sử dụng chúng.
        Input.SetJoyMotionSensorsEnabled(0, true);

        // (Thông báo cho người dùng tại đây rằng họ cần đặt joypad trên một bề mặt phẳng và chờ xác nhận.)

        // Bắt đầu quá trình hiệu chỉnh.
        CalibrateMotion();
    }

    public override void _Process(double delta)
    {
        // Chỉ di chuyển đối tượng nếu các cảm biến chuyển động của joypad đã được hiệu chỉnh.
        if (Input.IsJoyMotionSensorsCalibrated(0))
        {
            MoveObject(delta);
        }
    }

    private async Task CalibrateMotion()
    {
        Input.StartJoyMotionSensorsCalibration(0);

        // Chờ một khoảng thời gian.
        await ToSignal(GetTree().CreateTimer(1.0), SceneTreeTimer.SignalName.Timeout);

        Input.StopJoyMotionSensorsCalibration(0);
        // Joypad hiện đã được hiệu chỉnh.
    }

    private void MoveObject(double delta)
    {
        Node3D node = ... ; // Đặt object của bạn ở đây.
        Vector3 gyro = Input.GetJoyGyroscope(0);
        Vector3 rotation = node.Rotation;
        rotation.X -= -gyro.Y * GyroSensitivity * (float)delta; // Sử dụng phép xoay quanh trục Y (yaw) ở đây.
        rotation.Y += -gyro.X * GyroSensitivity * (float)delta; // Sử dụng phép xoay quanh trục X (pitch) ở đây.
        node.Rotation = rotation;
    }

\ ``amplitude`` là cường độ rung, với giá trị nằm trong khoảng từ ``0.0`` đến ``1.0``. Nếu được đặt thành ``-1.0``, cường độ rung mặc định của thiết bị sẽ được sử dụng.

\ **Lưu ý:** Phương thức này được triển khai trên Android, iOS và Web. Phương thức này không có tác dụng trên các nền tảng khác.

\ **Lưu ý:** Đối với Android, :ref:`vibrate_handheld()<class_Input_method_vibrate_handheld>` yêu cầu bật quyền ``VIBRATE`` trong export preset. Nếu không, :ref:`vibrate_handheld()<class_Input_method_vibrate_handheld>` sẽ không có tác dụng.

\ **Lưu ý:** Đối với iOS, việc chỉ định thời lượng chỉ được hỗ trợ trên iOS 13 trở lên.

\ **Lưu ý:** Đối với Web, không thể thay đổi biên độ.

\ **Lưu ý:** Một số trình duyệt web như Safari và Firefox trên Android không hỗ trợ :ref:`vibrate_handheld()<class_Input_method_vibrate_handheld>`.

\ **Lưu ý:** Các cài đặt của thiết bị như bật/tắt rung, chế độ "không làm phiền" hoặc bật/tắt phản hồi xúc giác cụ thể có thể ngăn các hiệu ứng :ref:`vibrate_handheld()<class_Input_method_vibrate_handheld>`.
