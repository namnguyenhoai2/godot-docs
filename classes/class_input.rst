Input
=====

**Kế thừa:** :ref:`Object<class_Object>`

Một singleton dùng để xử lý input.

.. rst-class:: classref-introduction-group

Mô tả
-----

Singleton **Input** xử lý thao tác nhấn phím, nút chuột và chuyển động, gamepad cũng như các input action. Có thể thiết lập action và các event tương ứng trong tab **Input Map** tại **Project > Project Settings**, hoặc bằng class :ref:`InputMap<class_InputMap>`.

\ **Lưu ý:** Các method của **Input** phản ánh trạng thái input toàn cục và không bị ảnh hưởng bởi :ref:`Control.accept_event()<class_Control_method_accept_event>` hoặc :ref:`Viewport.set_input_as_handled()<class_Viewport_method_set_input_as_handled>`, vì các method đó chỉ xử lý cách input được truyền qua :ref:`SceneTree<class_SceneTree>`.

Trả về ``true`` khi người dùng *ngừng* nhấn event của action trong frame hoặc physics tick hiện tại. Nó chỉ trả về ``true`` trong frame hoặc tick mà người dùng thả nút.

\ **Lưu ý:** Việc trả về ``true`` không có nghĩa là action *vẫn chưa* được nhấn. Một action có thể được thả rồi nhấn lại nhanh chóng, và ``true`` vẫn sẽ được trả về để không bỏ lỡ input.

Nếu ``exact_match`` là ``false``, nó sẽ bỏ qua các input modifier bổ sung đối với các event :ref:`InputEventKey<class_InputEventKey>` và :ref:`InputEventMouseButton<class_InputEventMouseButton>`, cũng như hướng đối với các event :ref:`InputEventJoypadMotion<class_InputEventJoypadMotion>`.

\ **Lưu ý:** Trong quá trình xử lý input (ví dụ: :ref:`Node._input()<class_Node_private_method__input>`), hãy sử dụng :ref:`InputEvent.is_action_released()<class_InputEvent_method_is_action_released>` để truy vấn trạng thái action của event hiện tại. \ **Lưu ý:** :ref:`AnimatedTexture<class_AnimatedTexture>`\ không được hỗ trợ làm con trỏ chuột tùy chỉnh. Nếu sử dụng :ref:`AnimatedTexture<class_AnimatedTexture>`, chỉ frame đầu tiên được hiển thị.

\ **Lưu ý:** Nên sử dụng các chế độ nén **Lossless**, **Lossy** hoặc **Uncompressed**. Có thể sử dụng chế độ nén **Video RAM**, nhưng dữ liệu sẽ được giải nén trên CPU, khiến thời gian tải lâu hơn và không tiết kiệm bộ nhớ so với các chế độ lossless.

\ **Lưu ý:** Trên nền tảng web, kích thước hình ảnh con trỏ tối đa được phép là 128×128. Hình ảnh con trỏ lớn hơn 32×32 cũng chỉ được hiển thị nếu toàn bộ hình ảnh con trỏ chuột nằm trong trang đối với `security reasons <https://chromestatus.com/feature/5825971391299584>`__.

.. rst-class:: classref-method

|void| **start_joy_motion_sensors_calibration**\ (\ device\: :ref:`int<class_int>`\ ) :ref:`🔗<class_Input_method_start_joy_motion_sensors_calibration>`

**Thử nghiệm:** Phương thức này có thể bị thay đổi hoặc xóa trong các phiên bản tương lai.

Bắt đầu quá trình calibration gyroscope của joypad đã chỉ định, nếu joypad có gyroscope.

Sau khi gyroscope của joypad được calibration chính xác (ví dụ: đặt yên trên bàn mà không xoay), :ref:`get_joy_gyroscope()<class_Input_method_get_joy_gyroscope>` sẽ trả về các giá trị gần hoặc bằng :ref:`Vector3.ZERO<class_Vector3_constant_ZERO>` khi joypad không bị xoay.

Dưới đây là ví dụ về cách sử dụng gyroscope của joypad và calibration gyroscope trong game:


.. tabs::

 .. code-tab:: gdscript

    const GYRO_SENSITIVITY = 10.0

    func _ready():
        # Trong ví dụ này, chúng ta chỉ sử dụng joypad đầu tiên được kết nối (id 0).
        if 0 not in Input.get_connected_joypads():
            return

        if not Input.has_joy_motion_sensors(0):
            return

        # Chúng ta phải bật các cảm biến chuyển động trước khi sử dụng chúng.
        Input.set_joy_motion_sensors_enabled(0, true)

        # (Hãy thông báo cho người dùng rằng họ cần đặt joypad trên một bề mặt phẳng và chờ xác nhận.)

        # Bắt đầu quá trình calibration.
        calibrate_motion()

    func _process(delta):
        # Chỉ di chuyển object khi các cảm biến chuyển động của joypad đã được calibration.
        if Input.is_joy_motion_sensors_calibrated(0):
            move_object(delta)

    func calibrate_motion():
        Input.start_joy_motion_sensors_calibration(0)

        # Chờ một khoảng thời gian.
        await get_tree().create_timer(1.0).timeout

        Input.stop_joy_motion_sensors_calibration(0)
        # Joypad hiện đã được calibration.

    func move_object(delta):
        var node: Node3D = ... # Đặt node của bạn ở đây.

        var gyro := Input.get_joy_gyroscope(0)
        node.rotation.x -= -gyro.y * GYRO_SENSITIVITY * delta # Sử dụng chuyển động xoay quanh trục Y (yaw) ở đây.
        node.rotation.y += -gyro.x * GYRO_SENSITIVITY * delta # Sử dụng chuyển động xoay quanh trục X (pitch) ở đây.

 .. code-tab:: csharp

    private const float GyroSensitivity = 10.0;

    public override void _Ready()
    {
        // Trong ví dụ này, chúng ta chỉ sử dụng joypad đầu tiên được kết nối (id 0).
        if (!Input.GetConnectedJoypads().Contains(0))
        {
            return;
        }

        if (!Input.HasJoyMotionSensors(0))
        {
            return;
        }

        // Chúng ta phải bật accelerometer và gyroscope trước khi sử dụng chúng.
        Input.SetJoyMotionSensorsEnabled(0, true);

        // (Hãy thông báo cho người dùng rằng họ cần đặt joypad trên một bề mặt phẳng và chờ xác nhận.)

        // Bắt đầu quá trình calibration.
        CalibrateMotion();
    }

    public override void _Process(double delta)
    {
        // Chỉ di chuyển đối tượng khi các cảm biến chuyển động của tay cầm chơi game đã được hiệu chỉnh.
        if (Input.IsJoyMotionSensorsCalibrated(0))
        {
            MoveObject(delta);
        }
    }

    private async Task CalibrateMotion()
    {
        Input.StartJoyMotionSensorsCalibration(0);

        // Hãy đợi một lát.
        await ToSignal(GetTree().CreateTimer(1.0), SceneTreeTimer.SignalName.Timeout);

        Input.StopJoyMotionSensorsCalibration(0);
        // Tay cầm chơi game hiện đã được hiệu chỉnh.
    }

    private void MoveObject(double delta)
    {
        Node3D node = ... ; // Đặt đối tượng của bạn ở đây.
        Vector3 gyro = Input.GetJoyGyroscope(0);
        Vector3 rotation = node.Rotation;
        rotation.X -= -gyro.Y * GyroSensitivity * (float)delta; // Sử dụng phép xoay quanh trục Y (yaw) ở đây.
        rotation.Y += -gyro.X * GyroSensitivity * (float)delta; // Sử dụng phép xoay quanh trục X (pitch) ở đây.
        node.Rotation = rotation;
    }
