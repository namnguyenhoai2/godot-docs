Mô tả
-----

Một :ref:`TextServer<class_TextServer>` giao diện giả lập không thực hiện chức năng gì. Hữu ích để giải phóng bộ nhớ khi không cần kết xuất văn bản, vì text server tiêu tốn nhiều tài nguyên. Nó cũng có thể được dùng để so sánh hiệu năng trong các GUI phức tạp nhằm kiểm tra tác động của việc kết xuất văn bản.

Một text server giả lập luôn khả dụng khi bắt đầu một project. Sau đây là cách truy cập nó:

::

    var dummy_text_server = TextServerManager.find_interface("Dummy")
    if dummy_text_server != null:
        TextServerManager.set_primary_interface(dummy_text_server)
        # If the other text servers are unneeded, they can be removed:
        for i in TextServerManager.get_interface_count():
            var text_server = TextServerManager.get_interface(i)
            if text_server != dummy_text_server:
                TextServerManager.remove_interface(text_server)

Đối số dòng lệnh ``--text-driver Dummy`` (phân biệt chữ hoa chữ thường) có thể được dùng để buộc :ref:`TextServer<class_TextServer>` "Dummy" trên bất kỳ project nào.
