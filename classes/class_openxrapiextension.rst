OpenXRAPIExtension
==================

**Kế thừa:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Cung cấp OpenXR API cho GDExtension.

.. rst-class:: classref-introduction-group

Mô tả
-----

**OpenXRAPIExtension** cung cấp OpenXR cho GDExtension. Nó cung cấp OpenXR API cho GDExtension thông qua phương thức :ref:`get_instance_proc_addr()<class_OpenXRAPIExtension_method_get_instance_proc_addr>`, và instance OpenXR thông qua :ref:`get_instance()<class_OpenXRAPIExtension_method_get_instance>`.

Nó cũng cung cấp các phương thức để truy vấn trạng thái khởi tạo OpenXR và các phương thức trợ giúp giúp sử dụng API với GDExtension dễ dàng hơn.
