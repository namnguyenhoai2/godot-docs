OS ==

**Kế thừa:** :ref:`Object<class_Object>`

Cung cấp quyền truy cập vào các chức năng hệ điều hành thông dụng.

.. rst-class:: classref-introduction-group

Mô tả
-----

Lớp **OS** bao bọc các chức năng phổ biến nhất để giao tiếp với hệ điều hành máy chủ, chẳng hạn như video driver, độ trễ, biến môi trường, thực thi binary, command line, v.v.

\ **Lưu ý:** Trong Godot 4, các hàm **OS** liên quan đến quản lý cửa sổ, clipboard và TTS đã được chuyển sang singleton :ref:`DisplayServer<class_DisplayServer>` (và lớp :ref:`Window<class_Window>`). Các hàm liên quan đến thời gian đã bị loại bỏ và chỉ có trong lớp :ref:`Time<class_Time>`.

.. _class_OS_method_execute:

.. rst-class:: classref-method

:ref:`int<class_int>` **execute**\ (\ path\: :ref:`String<class_String>`, arguments\: :ref:`PackedStringArray<class_PackedStringArray>`, output\: :ref:`Array<class_Array>` = [], read_stderr\: :ref:`bool<class_bool>` = false, open_console\: :ref:`bool<class_bool>` = false\ ) :ref:`🔗<class_OS_method_execute>`

Thực thi process được cung cấp theo cách *blocking*. File được chỉ định trong ``path`` phải tồn tại và có thể thực thi. Cơ chế phân giải system path sẽ được sử dụng. ``arguments`` được sử dụng theo thứ tự đã cho, phân tách bằng dấu cách và đặt trong dấu ngoặc kép.

Nếu cung cấp một mảng ``output``, toàn bộ shell output của process sẽ được nối vào ``output`` dưới dạng một phần tử :ref:`String<class_String>` duy nhất. Nếu ``read_stderr`` là ``true``, output của standard error stream cũng được nối vào mảng.

Trên Windows, nếu ``open_console`` là ``true`` và process là một console app, một cửa sổ terminal mới sẽ được mở.

Phương thức này trả về exit code của command, hoặc ``-1`` nếu process không thể thực thi.

\ **Lưu ý:** Main thread sẽ bị block cho đến khi command được thực thi kết thúc. Sử dụng :ref:`Thread<class_Thread>` để tạo một thread riêng không block main thread, hoặc sử dụng :ref:`create_process()<class_OS_method_create_process>` để tạo một process hoàn toàn độc lập.

Ví dụ, để lấy danh sách nội dung của working directory:


.. tabs::

 .. code-tab:: gdscript

    var output = []
    var exit_code = OS.execute("ls", ["-l", "/tmp"], output)

 .. code-tab:: csharp

    Godot.Collections.Array output = [];
    int exitCode = OS.Execute("ls", ["-l", "/tmp"], output);



Nếu bạn muốn truy cập shell built-in hoặc thực thi một composite command, bạn có thể gọi một shell dành riêng cho platform. Ví dụ:


.. tabs::

 .. code-tab:: gdscript

    var output = []
    OS.execute("CMD.exe", ["/C", "cd %TEMP% && dir"], output)

 .. code-tab:: csharp

    Godot.Collections.Array output = [];
    OS.Execute("CMD.exe", ["/C", "cd %TEMP% && dir"], output);



\ **Lưu ý:** Phương thức này được triển khai trên Android, Linux, macOS và Windows.

\ **Lưu ý:** Để thực thi một built-in command của Windows command interpreter, hãy chỉ định ``cmd.exe`` trong ``path``, ``/c`` làm đối số đầu tiên và command mong muốn làm đối số thứ hai.

\ **Lưu ý:** Để thực thi một built-in command của PowerShell, hãy chỉ định ``powershell.exe`` trong ``path``, ``-Command`` làm đối số đầu tiên và command mong muốn làm đối số thứ hai.

\ **Lưu ý:** Để thực thi một built-in command của Unix shell, hãy chỉ định tên shell executable trong ``path``, ``-c`` làm đối số đầu tiên và command mong muốn làm đối số thứ hai.

\ **Lưu ý:** Trên macOS, các ứng dụng sandbox chỉ được phép chạy những helper executable được nhúng và chỉ định trong quá trình export.

    # godot --headless --verbose --scene my_scene.tscn --custom

Command-line argument có thể được viết dưới bất kỳ dạng nào, bao gồm cả dạng ``--key value`` và ``--key=value``, để chúng được phân tích cú pháp chính xác, miễn là các command-line argument tùy chỉnh không xung đột với các argument của engine.

Bạn có thể đặt :ref:`ProjectSettings.editor/run/main_run_args<class_ProjectSettings_property_editor/run/main_run_args>` để định nghĩa các command-line argument mà editor sẽ truyền vào khi chạy project.

\ **Ví dụ:** Phân tích cú pháp các command-line argument thành một :ref:`Dictionary<class_Dictionary>` bằng cách sử dụng dạng ``--key=value`` cho các argument:


.. tabs::

 .. code-tab:: gdscript

    var arguments = {}
    for argument in OS.get_cmdline_args():
        if argument.contains("="):
            var key_value = argument.split("=")
            arguments[key_value[0].trim_prefix("--")] = key_value[1]
        else:
            # Các option không có argument sẽ xuất hiện trong dictionary,
            # với giá trị được đặt thành một chuỗi rỗng.
            arguments[argument.trim_prefix("--")] = ""

 .. code-tab:: csharp

    var arguments = new Dictionary<string, string>();
    foreach (var argument in OS.GetCmdlineArgs())
    {
        if (argument.Contains('='))
        {
            string[] keyValue = argument.Split("=");
            arguments[keyValue[0].TrimPrefix("--")] = keyValue[1];
        }
        else
        {
            // Các option không có argument sẽ xuất hiện trong dictionary,
            // với giá trị được đặt thành một chuỗi rỗng.

    }

Thay vào đó, hãy truyền double dash chuẩn của UNIX (``--``) rồi đến các argument tùy chỉnh; theo thiết kế, engine sẽ bỏ qua chúng. :ref:`String<class_String>` **get_locale**\ (\ ) |const| :ref:`🔗<class_OS_method_get_locale>`

Trả về locale của hệ điều hành host dưới dạng :ref:`String<class_String>` có cấu trúc ``language_Script_COUNTRY_VARIANT@extra``. Mọi chuỗi con sau ``language`` đều là tùy chọn và có thể không tồn tại.

- ``language`` - `language code <https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes>`_ gồm 2 hoặc 3 chữ cái, viết thường.

- ``Script`` - `script code <https://en.wikipedia.org/wiki/ISO_15924>`_ gồm 4 chữ cái, viết hoa chữ cái đầu.

- ``COUNTRY`` - `country code <https://en.wikipedia.org/wiki/ISO_3166-1>`_ gồm 2 hoặc 3 chữ cái, viết hoa.

- ``VARIANT`` - biến thể ngôn ngữ, khu vực và thứ tự sắp xếp. Biến thể có thể chứa bất kỳ số lượng từ khóa được phân tách bằng dấu gạch dưới nào.

- ``extra`` - danh sách các từ khóa bổ sung được phân tách bằng dấu chấm phẩy. Danh sách này có thể bao gồm thông tin về tiền tệ, lịch, thứ tự sắp xếp và hệ thống đánh số.

Nếu chỉ muốn mã ngôn ngữ thay vì locale được chỉ định đầy đủ từ hệ điều hành, bạn có thể sử dụng :ref:`get_locale_language()<class_OS_method_get_locale_language>`.

.. _class_OS_method_read_buffer_from_stdin:

.. rst-class:: classref-method

:ref:`PackedByteArray<class_PackedByteArray>` **read_buffer_from_stdin**\ (\ buffer_size\: :ref:`int<class_int>` = 1024\ ) :ref:`🔗<class_OS_method_read_buffer_from_stdin>`

Đọc dữ liệu đầu vào của người dùng dưới dạng dữ liệu thô từ standard input. Thao tác này có thể *blocking*, khiến cửa sổ bị treo nếu gọi :ref:`read_buffer_from_stdin()<class_OS_method_read_buffer_from_stdin>` trên main thread.

- Nếu standard input là console, phương thức này sẽ chặn cho đến khi chương trình nhận được ký tự xuống dòng trong standard input (thường là khi người dùng nhấn :kbd:`Enter`).

- Nếu standard input là pipe, phương thức này sẽ chặn cho đến khi đọc đủ một lượng dữ liệu cụ thể hoặc pipe được đóng.

- Nếu standard input là tệp, phương thức này sẽ đọc một lượng dữ liệu cụ thể (hoặc ít hơn nếu đạt đến cuối tệp) rồi trả về ngay lập tức.

\ **Lưu ý:** Phương thức này được triển khai trên Linux, macOS và Windows.

\ **Lưu ý:** Trên các bản build Windows đã export, hãy chạy executable console wrapper để truy cập terminal. Nếu standard input là console, việc gọi phương thức này mà không có console wrapper sẽ khiến chương trình bị treo vĩnh viễn. Nếu standard input là pipe hoặc tệp, có thể sử dụng phương thức này mà không cần console wrapper. Nếu cần một executable duy nhất có đầy đủ hỗ trợ console, hãy sử dụng một custom build được biên dịch với flag ``windows_subsystem=console``.

- ``OS.shell_open("C:/Users/name/Downloads")`` cũng hoạt động trên Windows và mở file explorer tại thư mục Downloads của người dùng.

- ``OS.shell_open("https://godotengine.org")`` mở trình duyệt web mặc định tại trang web Godot chính thức.

- ``OS.shell_open("mailto:example@example.com")`` mở email client mặc định với trường "To" được đặt thành ``example@example.com``. Xem `RFC 2368 - The mailto URL scheme <https://datatracker.ietf.org/doc/html/rfc2368>`__ để biết danh sách các trường có thể thêm.

Sử dụng :ref:`ProjectSettings.globalize_path()<class_ProjectSettings_method_globalize_path>` để chuyển đổi đường dẫn dự án ``res://`` hoặc ``user://`` thành đường dẫn hệ thống dùng với phương thức này.

\ **Lưu ý:** Sử dụng :ref:`String.uri_encode()<class_String_method_uri_encode>` để mã hóa các ký tự trong URL theo cách an toàn cho URL và có thể chuyển đổi. Điều này đặc biệt cần thiết đối với ký tự xuống dòng. Nếu không, :ref:`shell_open()<class_OS_method_shell_open>` có thể không hoạt động chính xác trong dự án được export sang nền tảng Web.

\ **Lưu ý:** Phương thức này được triển khai trên Android, iOS, Web, Linux, macOS và Windows.

:ref:`Error<enum_@GlobalScope_Error>` **shell_show_in_file_manager**\ (\ file_or_dir_path\: :ref:`String<class_String>`, open_folder\: :ref:`bool<class_bool>` = true\ ) :ref:`🔗<class_OS_method_shell_show_in_file_manager>`

Yêu cầu OS mở file manager, điều hướng đến ``file_or_dir_path`` đã cho và chọn tệp hoặc thư mục đích.

Nếu ``open_folder`` là ``true`` và ``file_or_dir_path`` là đường dẫn thư mục hợp lệ, OS sẽ mở file manager và điều hướng đến thư mục đích mà không chọn gì.

Sử dụng :ref:`ProjectSettings.globalize_path()<class_ProjectSettings_method_globalize_path>` để chuyển đổi đường dẫn dự án ``res://`` hoặc ``user://`` thành đường dẫn hệ thống dùng với phương thức này.

\ **Lưu ý:** Phương thức này hiện chỉ được triển khai trên Windows và macOS. Trên các nền tảng khác, phương thức này sẽ fallback về :ref:`shell_open()<class_OS_method_shell_open>` với đường dẫn thư mục là ``file_or_dir_path`` được thêm tiền tố ``file://``.

|void| **unset_environment**\ (\ biến\ môi\ trường\: :ref:`String<class_String>`\ ) |const| :ref:`🔗<class_OS_method_unset_environment>`

Xóa biến môi trường đã cho khỏi môi trường hiện tại, nếu biến đó tồn tại. Tên ``variable`` không được để trống hoặc chứa ký tự ``=``. \ **Lưu ý:** Tên biến môi trường phân biệt chữ hoa chữ thường trên tất cả các nền tảng ngoại trừ Windows.
