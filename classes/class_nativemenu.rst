NativeMenu
==========

**Kế thừa:** :ref:`Object<class_Object>`

Một interface máy chủ cho các menu native của OS.

.. rst-class:: classref-introduction-group

Mô tả
-----

**NativeMenu** xử lý quyền truy cập cấp thấp vào thanh menu global native và các popup menu của OS.

\ **Lưu ý:** Đây là API cấp thấp; hãy cân nhắc sử dụng :ref:`MenuBar<class_MenuBar>` với :ref:`MenuBar.prefer_global_menu<class_MenuBar_property_prefer_global_menu>` được đặt thành ``true``, và :ref:`PopupMenu<class_PopupMenu>` với :ref:`PopupMenu.prefer_native_menu<class_PopupMenu_property_prefer_native_menu>` được đặt thành ``true``.

Để tạo một menu, hãy sử dụng :ref:`create_menu()<class_NativeMenu_method_create_menu>`, thêm các mục menu bằng các phương thức của ``add_*_item``. Để xóa một menu, hãy sử dụng :ref:`free_menu()<class_NativeMenu_method_free_menu>`.

::

    var menu

    func _menu_callback(item_id):
        if item_id == "ITEM_CUT":
            cut()
        elif item_id == "ITEM_COPY":
            copy()
        elif item_id == "ITEM_PASTE":
            paste()

    func _enter_tree():
        # Tạo menu mới và thêm các mục:
        menu = NativeMenu.create_menu()
        NativeMenu.add_item(menu, "Cut", _menu_callback, Callable(), "ITEM_CUT")
        NativeMenu.add_item(menu, "Copy", _menu_callback, Callable(), "ITEM_COPY")
        NativeMenu.add_separator(menu)
        NativeMenu.add_item(menu, "Paste", _menu_callback, Callable(), "ITEM_PASTE")

    func _on_button_pressed():
        # Hiển thị popup menu tại vị trí chuột:
        NativeMenu.popup(menu, DisplayServer.mouse_get_position())

    func _exit_tree():
        # Xóa menu khi không còn cần thiết:
        NativeMenu.free_menu(menu)
