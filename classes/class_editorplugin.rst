EditorPlugin
============

**Kế thừa:** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**Được kế thừa bởi:** :ref:`GridMapEditorPlugin<class_GridMapEditorPlugin>`

Được editor sử dụng để mở rộng chức năng.

.. rst-class:: classref-introduction-group

Mô tả
-----

Plugin được sử dụng để mở rộng chức năng của editor. Các loại plugin phổ biến nhất là plugin chỉnh sửa một loại node hoặc resource nhất định, plugin import và plugin export. Xem thêm :ref:`EditorScript<class_EditorScript>` để thêm các hàm vào editor.

\ **Lưu ý:** Một số tên trong class này có chứa "left" hoặc "right" (ví dụ: :ref:`DOCK_SLOT_LEFT_UL<class_EditorPlugin_constant_DOCK_SLOT_LEFT_UL>`). Các API này giả định layout từ trái sang phải và sẽ bị đảo ngược khi sử dụng layout từ phải sang trái. Những tên này được giữ lại vì lý do tương thích.

:ref:`String<class_String>` **_get_unsaved_status**\ (\ for_scene\: :ref:`String<class_String>`\ ) |virtual| |const| :ref:`🔗<class_EditorPlugin_private_method__get_unsaved_status>`

Ghi đè phương thức này để cung cấp thông báo tùy chỉnh liệt kê các thay đổi chưa lưu. Editor sẽ gọi phương thức này khi thoát hoặc khi đóng một scene, đồng thời hiển thị chuỗi được trả về trong hộp thoại xác nhận. Trả về chuỗi rỗng nếu plugin không có thay đổi chưa lưu.

Khi đóng một scene, ``for_scene`` là đường dẫn đến scene đang được đóng. Bạn có thể dùng nó để xử lý các resource tích hợp trong scene đó.

    func _get_unsaved_status(for_scene):
        if not unsaved:
            return ""

        if for_scene.is_empty():
            return "Save changes in MyCustomPlugin before closing?"
        else:
            return "Scene %s has changes from MyCustomPlugin. Save before closing?" % for_scene.get_file()

    func _save_external_data():
        unsaved = false

Nếu plugin không có thay đổi riêng cho scene, bạn có thể bỏ qua các lệnh gọi khi đóng scene:

::

    func _get_unsaved_status(for_scene):
        if not for_scene.is_empty():
            return ""

|void| **add_undo_redo_inspector_hook_callback**\ (\ callable\: :ref:`Callable<class_Callable>`\ ) :ref:`🔗<class_EditorPlugin_method_add_undo_redo_inspector_hook_callback>`

Gắn một callback vào quá trình tạo hành động undo/redo khi một thuộc tính được sửa đổi trong inspector. Ví dụ: cách này cho phép lưu các thuộc tính khác có thể bị mất khi một thuộc tính nhất định được sửa đổi.

Callback phải có 4 đối số: :ref:`Object<class_Object>` ``undo_redo``, :ref:`Object<class_Object>` ``modified_object``, :ref:`String<class_String>` ``property`` và :ref:`Variant<class_Variant>` ``new_value``. Theo thứ tự, chúng lần lượt là đối tượng :ref:`UndoRedo<class_UndoRedo>` được inspector sử dụng, đối tượng hiện đang được sửa đổi, tên của thuộc tính được sửa đổi và giá trị mới mà thuộc tính sắp nhận.
